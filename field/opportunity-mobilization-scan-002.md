## 4. The exact residual is now much narrower

The only interesting missing edge left is:

> **Can a local licensed provider execute one OEM-defined field microtask under the manufacturer's task specification, brand/white-label rules, evidence requirements and acceptance criteria, with remote OEM escalation when needed?**

Examples:

```text
one site survey / interface measurement
one operating-condition test
one SAT checklist execution
one installation/commissioning assistance visit
one diagnosis + evidence-capture visit
```

The rooter would not sell “an engineer”.

It would route:

```text
OEM-defined task
→ qualified local capability
→ remote OEM support if required
→ timestamped evidence / measurements / test data
→ acceptance
→ settlement
```

### Rooter role

- task schema;
- provider qualification;
- routing;
- remote-OEM coordination;
- evidence/acceptance;
- settlement;
- reputation history.

### Rooter non-role

- no founder travel;
- no unlicensed electrical engineering;
- no assumption of technical liability that belongs to licensed actors/OEM;
- no manual recruitment for every single task.
