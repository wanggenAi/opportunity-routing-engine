## 3. The closest tungsten-alloy pain is already counterevidenced

A 2026 public case from 西北工业集团 describes a genuine large high-density tungsten-alloy problem:

- conventional processing left the billet core with very poor ductility;
- core elongation was around 2%;
- demanding applications need much better internal mechanical uniformity.

This looks close to the measured W-Ni-Fe strength improvement.

But the same named producer reports that it already solved the problem with a **multi-step sintering process**:

- core elongation increased to about 20%;
- tensile strength remained above 900 MPa;
- the process was described as ready for industrial use.

Source:

- https://finance.sina.com.cn/enterprise/central/2026-03-26/doc-inhsicus0268793.shtml

Therefore:

```text
TUNGSTEN-ALLOY PROPERTY PAIN
!=
MISSING EDGE TO ATOMIC-CLUSTER POWDER
```

An incumbent process already solves a closely related constraint.
