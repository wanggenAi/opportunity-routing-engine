# Opportunity Mobilization Scan 011 — trust/condition friction is often already inside the market

Date: 2026-09-18

## Result

Fresh Scan 011 started **after** a secondary market already existed.

The search question was:

> seller exists, buyer exists, marketplace exists — but does the transaction still fail because nobody can cheaply prove condition, grade, authenticity, provenance or acceptance?

Across the tested verticals:

# `RETAINED_CANDIDATES = 0`

The new rule is:

# `ACCEPTANCE / TRUST PROBLEM != OPEN CONTROL-PLANE GAP`

Mature vertical markets often absorb the trust layer themselves.

## 1. Retired photovoltaic modules — closed

This was initially an excellent structural fit.

The industry itself publicly describes old PV circulation problems around:

- condition classification;
- residual performance;
- reuse eligibility;
- testing;
- trustworthy pricing.

But reality has already moved.

### Standard layer

`GB/T 45075-2024` — retired PV-module echelon-use specification — is already in force.

### Policy layer

2026 central guidance explicitly calls for:

- retirement evaluation;
- inspection/testing methods;
- component trading platforms;
- standardized comprehensive reuse.

### Market layer

A 2026 PV reuse platform now combines:

```text
SELL
→ EL / POWER TEST
→ CONDITION SCORE
→ TRACEABILITY
→ PRICE
→ BUY
→ RECYCLE / REUSE
```

That is almost exactly the Rooter control plane this scan was looking for.

Judgment:

`CLOSED_NEWLY_INTEGRATED_VERTICAL_ROUTE`

## 2. Used machine tools — closed

Used CNC/machine-tool transactions have obvious hidden-state risk:

- geometry accuracy;
- spindle condition;
- electrical system;
- wear;
- maintenance history.

But current used-machine platforms already advertise:

- multi-step inspection;
- precision checks;
- performance testing;
- electrical inspection;
- detailed inspection reports;
- escrow / transaction guarantee;
- dispute support;
- logistics.

So the actual channel is no longer:

```text
LISTING
→ TRUST BUYER TO GUESS
```

It is increasingly:

```text
LISTING
→ INSPECT
→ REPORT
→ GUARANTEE
→ SETTLE
→ SHIP
```

Judgment:

`CLOSED_INTEGRATED_INSPECTION_ESCROW_ROUTE`

Sources:

- https://www.wiek.cn/
- https://www.jd35.com/

## 4. Scarce / secondary electronic components — closed

This was the strongest minimum-service-unit test.

The real buyer fear is:

- counterfeit IC;
- re-marked chip;
- refurbished chip;
- wrong batch;
- solderability issue;
- unknown internal die.

If independent verification were expensive/high-minimum, there might be a Rooter edge.

But current market pricing already goes down to:

- appearance test: tens of RMB;
- X-Ray: low hundreds;
- decap: low hundreds;
- combined verification packages: low hundreds.

The service unit is already tiny.

Component marketplaces also add:

- supplier qualification;
- authenticated-stock labels;
- physical inspection;
- random audits.

So:

```text
SMALL LOT
+
HIGH TRUST RISK
```

still does not create whitespace.

Judgment:

`CLOSED_LOW_MINIMUM_UNIT_VERIFICATION_ROUTE`

Sources:

- https://www.ickey.cn/iqc
- https://www.iclabcn.com/service/ic/
- https://www.hqew.com/zt/yuanzhuang
- https://about.hqew.com/OriginalStock/buyer

# Cross-industry result

The same mechanism replicated across very different markets:

```text
SECONDARY MARKET STARTS AS:
LISTING / MATCHING

THEN MATURES INTO:
INSPECTION
→ GRADING
→ PROVENANCE
→ REPORT
→ PRICING
→ ESCROW
→ LOGISTICS
→ WARRANTY
```

That is precisely why a generic:

> “I will add trust between buyers and sellers”

thesis is too weak.

The market often does it itself.

# Next search zone

Fresh Scan 012 should stop searching generic condition verification.

The next potentially harder failure is:

# `SPECIFICATION / SUBSTITUTION TRANSLATION`

Structure:

```text
BUYER HAS A FUNCTIONAL REQUIREMENT
+
SUPPLY EXISTS
+
MARKET / DISTRIBUTOR EXISTS
+
BUT
BUYER AND SUPPLIER USE DIFFERENT:
  MODEL NUMBERS
  STANDARDS
  INTERFACES
  MATERIAL GRADES
  DIMENSIONS
  PERFORMANCE ENVELOPES
+
WRONG SUBSTITUTE HAS REAL COST
+
CURRENT CATALOG / SEARCH / DISTRIBUTOR ROUTE STILL FAILS
```

The target is not generic product search.

Retain only if:

- the failed translation is observed repeatedly;
- a named buyer pays a measurable current cost;
- existing distributor/application-engineer routes do not already solve it;
- compatibility can be accepted objectively;
- Rooter can route rather than become the permanent engineer.

Do not commit Scan 012 merely because equivalent-part selection is technically difficult.
