## 1. Question

Scan 007 selected VT-B because one translated older-adult capability can support many downstream flows.

The next question is not:

> Can older capability be sold?

It is:

> **How do successful operators decide which hidden capability deserves investment, what form it should become, and where it should be routed?**

If that function repeats, it may be the riverbed beneath multiple surface products.

## 2. Fengtai shows an explicit selection funnel

The current Fengtai "悦·丰匠" flow does not develop every discovered capability equally.

Public reporting shows:

- community-level discovery identified 40+ older residents with special capabilities;
- five were appointed core artisans in the initial brand launch;
- a professional design partner planned to select 20 works for deep development;
- a first batch of 30 products was planned for market launch;
- a dedicated company now owns product design, production and marketing;
- IP protection and artisan-level certification are being explored.

Source:

- https://www.bjft.gov.cn/fengtaishibao/html/2026-02/04/content_9501_19279615.htm

This means:

```text
DISCOVER MANY
→ SELECT FEW
→ DEEPEN SELECTED ASSETS
→ ROUTE TO FORM / CHANNEL
```

Selection happens before scale.

That is important because:

`OLDER CAPABILITY EXISTS != MARKETABLE ASSET`

## 3. Shanghai shows value-form switching from feedback

The Tǎmadrama retirement-market example provides the clearest routing loop.

The operator started from:
- retired makers;
- youth design;
- product retail.

The project then:
- attracted 40+ original brands;
- used strong street/pop-up traffic as evidence to move into a core shopping mall.

But after entering the mall, the operator observed:

> product-only retail was not sufficiently attractive to the surrounding resident customer base.

So the operator changed the value form:
- added hands-on pottery classes;
- used community recognition to add livestream selling;
- reported one livestream session above RMB10,000.

Source:

- https://www.jingan.gov.cn/rmtzx/003008/003008004/20250916/dde899c5-7220-4a10-ab75-f77a2c1f3c25.html

This is not simply "more marketing."

The underlying capability was rerouted:

```text
HANDMADE CAPABILITY
→ PRODUCT
→ weak fit in new context
→ EXPERIENCE / CLASS
→ LIVESTREAM / CHANNEL
```

So:

`PILOT / FEEDBACK CAN CHANGE VALUE FORM`

This is direct evidence of routing judgment.

## 6. But the current routing layer is highly manual

The observed systems still depend heavily on:

- community workers discovering people;
- social organizations building trust;
- designers choosing works;
- operators deciding what to deepen;
- shop operators reading customer behavior;
- people manually choosing product vs class vs livestream;
- relationship-based channel linkage.

So the function is real.

But the current production method is:

`MANUAL CURATOR / OPERATOR JUDGMENT`

This creates two very different possibilities.

### Possibility A — real reusable orchestration primitive

There may be recurring selection/routing logic that can be learned across cases.

### Possibility B — irreducible curator work

Success may depend on:
- aesthetic taste;
- local context;
- founder intuition;
- relationships;
- category-specific knowledge.

If B is true, there is no broad reusable missing edge.

Fengtai also uses a funnel:

- selected work development;

These show:

`TEST → FEEDBACK → REROUTE`

But the system has **not** yet proven:

- a reusable cross-category scoring model;
- systematic learning from one elder asset to the next unrelated elder asset;
- a cheap kill test before expensive design labor;
- participant referral as the dominant source channel;
- portable revenue-sharing/rights rules.

Current state:

`LEARNING LOOP = EARLY PARTIAL EVIDENCE`
