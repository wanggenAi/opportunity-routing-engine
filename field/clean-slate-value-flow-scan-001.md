## 3. Fresh Flow 001 — Local commercial content micro-orders

### Side A

Young creators / students / freelancers already know how to:

- shoot with phone/camera;
- edit with CapCut/Premiere;
- make product clips;
- make platform-ready short-form content;
- work flexibly for additional income and portfolio.

### Side B

Businesses already pay for bounded content work.

A current Jiangsu machinery company explicitly advertises part-time video production with:

- remote production;
- settlement by shoot / by video;
- buyer confirmation as the completion standard;
- one or two defined revision rounds.

Source:

- https://www.zhaopin.com/jobdetail/CC622881630J40871045001.htm

Other current Jiangsu part-time content jobs already use per-video settlement.

Source:

- https://www.zhaopin.com/jobdetail/CC867397270J40885396005.htm

Xuzhou itself has current content/video demand across e-commerce and commercial promotion.

Sources:

- https://www.zhaopin.com/zhaopin/927c74c3cadb4e55b10a92c84045d9b7/
- https://www.zhaopin.com/jobdetail/CCL1526321110J40863610701.htm

### Why the flow is attractive

It is already naturally divisible:

```text
one video
one shoot
one batch
one deadline
one acceptance
one payment
```

No marketplace has to be built first.

### What we would sell

Not “marketing consulting.”

Not “full-service new media.”

A first unit can be:

> One defined product video package, delivered by a matched local creator, with a fixed brief, deadline, revision limit and acceptance rule.

### Where we earn

```text
buyer task price
-
creator delivery price
-
real operating cost
=
orchestration margin
```

The margin is a hypothesis until buyer budget and creator quote are bound.

### Main risk

After the first successful order, buyer and creator may bypass us.

We only have durable value if we continue owning something useful:

- continuous task intake;
- creator replacement;
- quality consistency;
- turnaround guarantee;
- multi-city/multi-skill coverage;
- acceptance and exception handling.

Current state:

`DIRECT_PAID_FLOW_OBSERVED / OPERATOR_EDGE_UNPROVEN`

- https://www.zhaopin.com/jobdetail/CCL1528060070J40932076112.htm

### The correct first unit

Not:

> “AI transformation.”

Instead:

> “Take this one repetitive workflow and make it run automatically against these test cases.”

Examples:

- one Excel/report automation;
- one document knowledge base;
- one form → CRM → notification flow;
- one bounded data cleanup/import.

### Money path

```text
SME pays for one accepted workflow
→ matched implementer delivers
→ operator scopes + matches + tests
→ operator retains margin
```

## 5. Fresh Flow 003 — Local-presence field microtasks

This is the cleanest illustration of the original commercial logic.

### Side A

A local student / young person has:

- available time;
- a smartphone;
- local mobility;
- local language/culture;
- desire for short paid work.

They do not need a full-time job to provide value.

### Side B

A remote company has a task that literally cannot be completed remotely.

A current real example appeared on **2026-09-10**:

A Polish building-materials company needed one person in Shanghai for one exhibition day to:

- find relevant manufacturers;
- ask a prepared list of questions;
- check product/certification basics;
- collect cards/catalogues;
- take photos;
- submit a short summary.

It explicitly said:

- students are acceptable;
- no complex professional judgment is required;
- instructions will be supplied;
- compensation is roughly **RMB 700–800 for one day**.

Source:

- https://www.reddit.com/r/AskChina/comments/1wcbrn7/

This is almost the pure form of the model:

```text
remote buyer cannot be physically present
+
local young person can easily be present
+
clear checklist
+
clear evidence packet
+
clear one-day price
=
immediate value connection
```

### This pattern exists in Xuzhou too

Current Xuzhou listings show firms paying local people to visit businesses, verify physical conditions and return photo evidence.

Source:

- https://www.zhaopin.com/zhaopin/4d2ee7740bdc429aa644318adca9cef6/

The exact bank-use case is not our target. It is proof that:

```text
PHYSICAL PRESENCE
+
CHECKLIST
+
PHOTO EVIDENCE
```

can already be turned into a paid microtask.

### What we would connect

Safe, legitimate examples only:

- exhibition research;
- shop/market observation;
- supplier existence check;
- product display check;
- public-location photo/video;
- document/sample pickup where lawful;
- local appointment attendance;
- simple buyer-prepared interviews;
- event assistance.

Exclude:

- debt collection;
- covert surveillance;
- trespass;
- regulated professional inspections;
- unsafe confrontation;
- private-person tracing.

### Money path

```text
remote buyer task price
→ local executor task fee
→ operator sourcing / briefing / QA / replacement margin
```

### Why the operator can matter

The buyer often does not merely need “a random person.”

They need:

- somebody who will actually show up;
- evidence in the requested format;
- language/local fit;
- replacement if the first person fails;
- a single accountable contact.

That is a real orchestration function.

### Counterevidence

This is not an empty market.

There are already local/global execution services offering store visits, field research and local-person task execution.

Example:

- https://wisefieldinsights.com/

So the opportunity is **not** “invent local task outsourcing.”

The question is whether there is a narrow, cheap, trusted, fast segment that existing agencies/platforms serve badly enough for a lightweight router to keep margin.

Current state:

`DIRECT_PAID_FLOW_OBSERVED / HIGH_IMMEDIACY / REPEATABILITY_AND_OPERATOR_EDGE_UNPROVEN`
