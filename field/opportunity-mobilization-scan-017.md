# Cross-industry learning

Scan 017 exposes two very different reasons why “group commerce” survives.

## Type A — the group is an early control plane

When the pain is large enough, the industry itself can formalize:

```text
CHAT
→ STANDARD ORDER FIELDS
→ CAPACITY STATUS
→ ACCEPT / DECLINE
→ PROGRESS
→ QUALITY
→ REPUTATION
```

Yangzhou plush toys are already doing this.

Rooter arrives too late.

## Type B — the group survives because people want less intermediation

The group can simply be:

```text
INFORMATION
→ DIRECT CONTACT
→ OFF-GROUP DEAL
```

That can be attractive because:

- low/no commission;
- repeat relationships can go direct;
- parties control price themselves.

In that case, adding:

- escrow;
- acceptance;
- settlement;
- heavier process;

may add cost that participants are deliberately avoiding.

So:

# `INFORMAL MARKET PERSISTS != USERS WANT MORE PLATFORM`

# Next search zone

Fresh Scan 018 should investigate **platform-bypass persistence**.

Search cases where:

```text
MATURE PLATFORM EXISTS
+
ACTORS KNOW IT EXISTS
+
ACTORS STILL MOVE TO:
  WECHAT
  DIRECT CONTACT
  PRIVATE GROUP
  OFF-PLATFORM REPEAT DEAL
```

Then distinguish:

### Possible opportunity

They leave because the platform still cannot handle:

- urgency;
- micro-unit economics;
- live availability;
- acceptance;
- unusual specification;
- local trust;
- replacement.

### Not an opportunity

They leave because they want:

- no commission;
- direct repeat relationship;
- less paperwork;
- regulatory/tax evasion;
- to bypass the intermediary after first match.

Rooter is relevant only in the first case and only if its added control-plane value exceeds the friction/cost users are intentionally avoiding.

Do not persist Scan 018 unless judgment materially changes.
