## 1. Question

Scan 009 demoted generic value-form routing as the distinctive missing edge.

The remaining question is upstream:

> **Before ordinary product, market and channel mechanisms can work, how does a useful older-adult capability become visible at all?**

This scan focuses only on source-side discovery and legibility.

---

## 2. Current discovery is usually high-touch

Current silver-talent/community systems repeatedly use:

- phone contact;
- home visits;
- questionnaires;
- grid/community workers;
- building-by-building screening;
- "carpet-style" mapping;
- organization recommendation;
- resident recommendation;
- personal self-nomination;
- targeted invitation.

Sources:
- https://www.hnlgbj.gov.cn/lgbj/20/22/content_25813.html
- https://www.sclgb.gov.cn/fhzy-1/1511851884577554432.shtml
- https://www.hnlgbj.gov.cn/lgbj/25/26/content_26629.html

That matters because:

`HIDDEN CAPABILITY DOES NOT AUTOMATICALLY ENTER A DATABASE`

Trusted local actors actively manufacture visibility.

---

## 3. Self-nomination only works when a person can already describe their value

Current programs also use:

- personal application;
- unit recommendation;
- industry recommendation;
- targeted invitation.

Sources:
- https://www.hnjjbs.com/article/2026-09/178840547769131.html
- https://cncaprc.gov.cn/ylxdtsgz/772798.jhtml

But current intake forms remain strongly structured around:
- former work unit;
- former title/position;
- predefined service fields;
- broad expertise categories.

Example:
- https://www.wenjuan.com/s/JJ7famp/

This favors people whose value already has institutional language.

It is less suited to a person whose real asset sounds like:

> "I have always done this."

> "People in the neighborhood ask me for this."

> "I know this local history."

> "I can judge this by experience."

> "I have cooked/raised children/repaired things this way for decades."

That kind of capability may be real without being self-described as a market asset.

---

## 4. Retirement may create a legibility break

While employed, capability has an institutional address:

```text
EMPLOYER
+ ROLE
+ TITLE
+ PROJECT
+ COLLEAGUES
+ RECURRING DEMAND
```

After retirement, the capability may remain while the address disappears.

Some current programs appear to recognize this implicitly.

For example, current retirement-management practice can create:
- one-person-one-file records;
- immediate silver-talent-pool intake;
- profiles including professional specialties and interests.

Source:
- https://www.hnlgb.gov.cn/2025/07-08/425296.html

This is important.

A retirement-transition capture point can preserve legibility before the person becomes simply:

> "a retired resident."

Current interpretation:

`RETIREMENT LEGIBILITY BREAK = FORMATION HYPOTHESIS STRENGTHENED`

This is an inference from converging evidence, not a directly measured national statistic.

---

## 5. Formal expert pools and everyday hidden capability are not the same thing

### Formal systems see well

Current professional/industrial silver-talent systems are built to see:

- professional titles;
- technical achievements;
- former employment;
- current employment relationship;
- verified professional contribution;
- health and service willingness.

Example:
- https://gxj.longyan.gov.cn/xxgk/qtxx/202606/t20260608_2296152.htm

Other public pools classify people into domains such as:
- education;
- law;
- medicine;
- agriculture;
- technology;
- party/community work;
- culture.

Sources:
- https://www.hnjjbs.com/article/2026-09/178840547769131.html
- https://www.hnlgbj.gov.cn/lgbj/20/content_26792.html

### Community discovery sees different things

Community systems that want ordinary capability explicitly expand their map toward:

- interests;
- hobbies;
- local hidden "能人";
- practical community capability;
- non-professional craft.

Sources:
- https://www.hnlgbj.gov.cn/lgbj/20/22/content_25813.html
- https://www.hnlgbj.gov.cn/lgbj/20/content_26792.html
- https://www.bjft.gov.cn/fengtaishibao/html/2026-06/29/content_9500_19659829.htm

So there appears to be a real visibility divide:

```text
FORMAL TALENT SYSTEM
→ GOOD AT CREDENTIALLED / NAMED CAPABILITY

LIFE-WORLD HIDDEN-ASSET DISCOVERY
→ REQUIRES ACTIVE ELICITATION / LOCAL KNOWLEDGE
```

## 6. Selection remains material

A large map does not mean every person becomes a useful node.

Longchang reports:

- 138 people mapped/registered;
- 53 admitted to the first pool.

Source:
- https://www.sclgb.gov.cn/fhzy-1/1511851884577554432.shtml

Approximate first-batch selection ratio:

`53 / 138 ≈ 38.4%`

Caution:

This is a public-service talent-pool filter.

It is **not** a market-value hit rate.

Fengtai gives another funnel:
- 40+ older residents with special capabilities discovered;
- five initially appointed as core artisans.

Source:
- https://www.bjft.gov.cn/fengtaishibao/html/2026-02/04/content_9501_19279615.htm

Again:

`DISCOVER MANY != ACTIVATE MANY`

## 7. Discovery maps decay

A human-capability map is not static.

Current systems use:
- quarterly mapping;
- half-year updates;
- annual review;
- dynamic entry/exit;
- periodic willingness/health/profile updates.

Sources:
- https://www.sclgb.gov.cn/fhzy-1/1511851884577554432.shtml
- https://www.hnjjbs.com/article/2026-09/178840547769131.html
- https://www.xinghua.gov.cn/xwzx/xhxc/art/2025/art_bf24f2199afb4ebdbdac86009f647148.html

So:

`HUMAN ASSET MAP != ONE-TIME DATABASE`

Capability, health, willingness, location and availability all change.

## 8. The strongest current discovery engine is local social infrastructure

Current examples repeatedly depend on:

- grid workers;
- community staff;
- retired-cadre systems;
- neighborhood organizations;
- local recommendations;
- existing resident trust.

One current mutual-aid program used 200+ grid workers for carpet-style mapping before service matching.

Source:
- https://www.hbshgzb.gov.cn/2026-06/05/content_9521193.htm

This is adjacent evidence rather than a VT-B commercial example.

But it exposes a real constraint:

> A private operator cannot simply assume the same right to knock on doors, access resident information or inherit community trust.

Current state:

`HIGH-TOUCH LOCAL-ACCESS DEPENDENCE = EVIDENCED`

## 9. Referral exists, but regenerative source acquisition is not proven

Current discovery channels include:

- organization recommendation;
- party-member recommendation;
- resident nomination;
- self-nomination;
- industry recommendation.

Sources:
- https://www.hnlgbj.gov.cn/lgbj/25/26/content_26629.html
- https://www.hnjjbs.com/article/2026-09/178840547769131.html

This proves:

`SOCIAL REFERRAL CHANNEL EXISTS`

It does **not** yet prove:

```text
ONE SUCCESSFUL ACTIVATION
→ ELDER REFERS ANOTHER HIGH-VALUE ELDER
→ NEW ASSET ENTERS
→ DISCOVERY COST FALLS
```

An adjacent community-governance model describes:

> core residents bring in other residents, and residents become new core participants.

Source:
- https://www.zyshgzb.gov.cn/n1/2026/0420/c462099-40705020.html

That shows social propagation is possible.

It is not direct evidence for hidden-asset commercial discovery.

Current state:

`REFERRAL CHANNEL EXISTS / SUCCESS-GENERATED LOOP NOT EVIDENCED`

## 11. The source-side formation now looks like this

```text
RETIREMENT / LATER-LIFE TRANSITION
→ PRIOR INSTITUTIONAL IDENTITY WEAKENS
→ SOME CAPABILITY LOSES ITS ADDRESS
→ ASSET BECOMES HOBBY / HABIT / MEMORY / LOCAL KNOWLEDGE
→ NORMAL MARKET/TALENT SYSTEM CANNOT ROUTE IT
→ ACTIVE LOCAL ELICITATION MAKES IT LEGIBLE AGAIN
→ ONLY THEN CAN SELECTION / TRANSLATION / MARKET WORK BEGIN
```

Working label:

`LATENT HUMAN-ASSET LEGIBILITY / ACTIVATION`

Current truth:

`SOURCE LEGIBILITY FRICTION = EVIDENCED`

But:

`PRIVATE REPLICABILITY = UNKNOWN`

`ECONOMIC VALUE DENSITY = UNKNOWN`

## 12. Why this may still die

This formation should be killed if any of the following becomes true:

1. hidden everyday assets have a very low useful-value hit rate;
2. discovery cost is too high relative to downstream value;
3. community/local trust is non-transferable to a private operator;
4. existing silver-talent/community systems already capture the economically useful assets;
5. AI/self-service makes elicitation so cheap that no orchestration layer remains;
6. the same problem is simply generic hidden-human-capital discovery and retirement adds no distinct economics;
7. activated assets rarely generate repeat downstream value.

## 14. Next truth boundary

Do **not** return to products.

Audit **value density and discovery economics**.

Search:

- among mapped people, how many become repeatedly useful;
- formal expert pools versus open-ended community capability maps;
- downstream utilization rates;
- repeated engagements per activated person;
- referral-generated source discovery;
- discovery labor required per useful asset;
- whether retirement-transition capture is cheaper than later rediscovery;
- whether asset maps accumulate durable local knowledge/trust.

The decisive question:

> **Is the hidden-asset pool dense and valuable enough that discovering it can be economically sustained?**

No product.

No pricing.

No outreach.
