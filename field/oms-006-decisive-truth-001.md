## 1. The low-price end is already productized

West.cn currently sells an AI security scan for **RMB 188 per website**.

Its official service states that the scan is used for:

- pre-launch security checks;
- third-party outsourced-code audit;
- legacy system security baselining.

The result is not described as fully autonomous: the service states that technical experts manually validate scan results.

AI repair is separately sold for **RMB 880 per website**.

Sources:

- https://newslist.west.cn/detail/1044
- https://sy.west.cn/paas/ai/index

This means a buyer who wants a cheap pre-launch risk screen already has a transaction unit that is:

```text
CODE INPUT
→ AUTOMATED ANALYSIS
→ EXPERT VALIDATION
→ REPORT
→ OPTIONAL REPAIR
```

There is no evidence that Rooter adds independent value merely by recreating that intake/report layer.

## 4. The tempting price-gap story is rejected

The market appears to have three visible bands:

```text
cheap automated scan
~ RMB 188

direct flexible engineer
~ hundreds to low thousands per day

formal security / code audit
~ thousands to tens of thousands+
```

It is tempting to say:

> therefore there must be a missing RMB 500–2,000 fixed senior-human review product.

That inference is not allowed.

```text
PRICE GAP
!=
CONNECTION PRESSURE
```

A buyer can already purchase a remote engineer in approximately that same economic unit.

No Chinese payer evidence was found showing that the buyer separately values:

> an independent reviewer-routing / report-standardization layer

enough to pay Rooter on top of existing direct or platform routes.

