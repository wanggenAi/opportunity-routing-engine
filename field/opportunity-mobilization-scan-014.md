## 3. Full manufacturing capacity / buyers locking future capacity — strong pull, wrong permission level

Current Jiangsu manufacturing has multiple full-capacity pockets.

The clearest signal is the transformer cluster.

Overseas buyers are reported to:

- stay at factories for outgoing inspection;
- reserve future capacity;
- accept long forward lead times.

This is extremely strong demand pull.

But the transaction is:

- highly engineered;
- qualification-heavy;
- often one-off/nonstandard;
- controlled through direct OEM relationships and mature supply-chain clusters.

Rooter would likely become:

- procurement agent;
- capacity broker;
- project coordinator;
- commercial negotiator.

That is not a low-permission routing control plane.

`NOT_LOW_PERMISSION_ROOTER_ROUTE`

## 4. Temporary industrial power mismatch — perfect pattern, already institutionalized

One Suzhou industrial-park case is almost a textbook latent connection:

```text
FACTORY A
→ full load
→ insufficient power
→ orders at risk

NEARBY FACTORY / PARK RESOURCE
→ idle capacity

PARK
→ coordinates temporary power connection
→ orders continue
```

This proves the pattern is real.

But it does not make it a Rooter opportunity.

Electrical connection is:

- safety-sensitive;
- asset-sensitive;
- permission-heavy.

And Jiangsu has already created a formal market structure for flexible load, explicitly recognizing:

- independent flexible-load resources;
- virtual power plants;
- load aggregators;
- market-based compensation.

So this exact control-plane idea is already being institutionalized in the power market.

Judgment:

`PATTERN_SENSOR_ONLY / REGULATED_ROUTE_ALREADY_FORMING`

# Scan 014 learning

Broad reality changes are useful.

But they are **not** a shortcut around the post-incumbent gate.

Across this scan:

```text
NEW STATE CHANGE
→ strong actor pressure
→ incumbent / institution / regulation adapts
→ generic missing edge disappears
```

The candidate must be found **after** that adaptation.

Not before it.
