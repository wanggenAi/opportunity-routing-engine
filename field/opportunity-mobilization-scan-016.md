# Opportunity Mobilization Scan 016 — manual workaround is only useful if it is still unresolved

Date: 2026-09-19

## Result

Scan 016 searched for the strongest kind of pre-platform signal:

```text
formal route does not fit
→ owner / employee manually transports, waits, borrows, calls acquaintances or uses informal groups
→ measurable time / money loss
```

Result:

# `RETAINED_CANDIDATES = 0`

The new rule is:

# `MANUAL WORKAROUND != CURRENT OPEN GAP`

A solved manual workaround proves the mechanism, not the opportunity.

---

## 1. 江苏本优机械 — textbook workaround, already solved

A large-bore liquid flowmeter previously had to be:

```text
dismantled
→ transported to Nanjing or farther
→ calibrated
→ transported back
→ reinstalled
```

The round trip took about half a month.

The production line stopped and orders were delayed.

In 2026 Xuzhou local full-range calibration capability became available and technicians performed on-site online calibration without dismantling or stopping production.

Source:

- https://www.zgjssw.gov.cn/shixianchuanzhen/xuzhou/202603/t20260316_8561864.shtml

This is exactly the structure the engine should hunt.

But the edge is already filled.

Judgment:

`SOLVED_MECHANISM_PRECEDENT / NOT_CANDIDATE`

---

## 2. 徐工特种工程机械 — repeated internal debugging, local capability closes it

A newly introduced automated online inspection system lacked a traceability method.

Internal technicians repeatedly adjusted it but the data remained unstable.

After one call to the Xuzhou inspection/testing center:

- a multidisciplinary team arrived the next day;
- the problem was closed in two days.

Same source:

- https://www.zgjssw.gov.cn/shixianchuanzhen/xuzhou/202603/t20260316_8561864.shtml

Again:

```text
INTERNAL MANUAL EFFORT
+
SPECIALIST GAP
```

was real.

But current local infrastructure already owns the flow.

Judgment:

`SOLVED_LOCAL_CAPABILITY_ROUTE / NOT_CANDIDATE`

---

## 3. Truck loading queues — manual waiting is real, but the unit is productized

A Jiangsu manufacturing/logistics case records drivers waiting roadside because loading/unloading depended on enterprise scheduling.

The local solution combined:

- parking coordination;
- ordered waiting;
- staggered loading.

Commercial yard/vehicle appointment systems also already productize:

- arrival reservation;
- queue order;
- gate dispatch;
- loading-slot scheduling.

Sources:

- https://jsnews.jschina.com.cn/nt/a/202508/t20250828_s68b00ea8e4b09ac140bc31b3.shtml
- https://www.sohu.com/a/1014009246_122717451

Judgment:

`SOLVED_OR_PRODUCTIZED_YARD_ROUTE`

## 4. Peer borrowing / hidden inventory / shared capacity — mechanism proven, local residual not bound

This is the most important Scan 016 mechanism.

Industry-association precedent documents firms using peer groups to:

- share workers/capacity for urgent orders;
- buy inventory from peers when normal procurement lead time is too slow;
- borrow tiny amounts of material for samples below supplier MOQ.

Source:

- https://www.sohu.com/a/756931274_121406675

In 2026 Yangzhou the same behavior has already been formalized into a plush-toy “small-order fast-return alliance” with:

- order sharing;
- capacity matching;
- standardized collaboration.

Source:

- https://yztoy.cn/nd.jsp?fromColId=2&id=265

Emergency electronic-component sourcing services also explicitly advertise mining hidden inventory from peer/upstream/downstream firms when normal market stock cannot meet the deadline.

Source:

- https://inotoday.cn/customized-sourcing/

So the mechanism is unquestionably real.

But a current Xuzhou residual was not bound.

For example, current Ma Po glass suppliers already advertise:

- dense local supporting supply;
- thousands of existing SKUs;
- small and large batch production;
- rapid scheduling;
- integrated caps/molds/cartons/deep-processing.

Sources:

- https://zh.gyglass.com/
- https://zh.gyglass.com/faq/

No named current Xuzhou buyer was found publicly documenting:

```text
urgent order
→ formal supplier cannot meet unit/speed
→ borrow from peer
→ measurable cost
→ workaround still unresolved
```

Judgment:

`MECHANISM_REAL / NO_CURRENT_XUZHOU_RESIDUAL_BOUND`

## 5. “Find acquaintances / use WeChat” claims — evidence too weak

Industrial marketing content often claims buyers still:

- find acquaintances;
- ask peers;
- search phone numbers;
- use informal groups.

That may be directionally true.

But without:

- named actor;
- recent event;
- actual workaround;
- time/cost;
- failed incumbent route;

it is not enough.

Judgment:

`REJECT_WEAK_EVIDENCE`

---

## 6. Phone/WeChat/Excel after-sales dispatch — internal SaaS problem

Some equipment-service teams still receive repair requests through:

- phone;
- WeChat;
- email;

then copy them to Excel and send them to engineer groups for manual assignment.

That is inefficient.

But it is an internal field-service/work-order software problem.

Current products already provide:

- multi-channel intake;
- dispatch;
- accountability;
- service history;
- reporting.

Sources:

- https://qingflow.com/knowledge/5142
- https://equipment.qingflow.com/

Judgment:

`CLOSED_INTERNAL_SOFTWARE_WORKFLOW`

```text

```

Scan 016 did not bind that final condition.

# Next search zone

Fresh Scan 017 should target **ad-hoc micro-networks that are already forming themselves**:

```text
actors repeatedly exchange:
  tiny inventory
  capacity
  tasks
  local help
  queue positions
through:
  peer groups
  association chats
  ad-hoc introductions
```

The signal is stronger when the network itself already exists but lacks:

- task schema;
- live availability;
- acceptance;
- trust history;
- settlement.

Require repeated transactions and current evidence.

Do not retain a pattern where an alliance/platform is already operating.
