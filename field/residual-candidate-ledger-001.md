# Operating rule after consolidation

A candidate is not active because it is intellectually interesting.

For a P0 candidate, we should be able to state:

1. a named or tightly bounded Actor already bears a real cost;
2. a real counterparty/resource/capability exists;
3. a partial flow/workaround already shows the connection pressure;
4. mature routes do not already solve the problem acceptably;
5. permissions are low enough to act;
6. input/output/acceptance can be bounded;
7. the smallest real test is reversible and can produce external truth within days.

If those conditions are not met, keep it as a sensor or watch item.

The next meaningful promotion must come from external truth, not from another attractive connection narrative.
