## RCL-003 — first concrete resource watch object

### Actor

**徐州国基原子制造有限公司**

### Why this is unusually clean for resource-first discovery

Jiangsu public reporting in June/July 2026 quotes the company's R&D engineer saying that the company has already produced special-metal atomic-cluster powder, but because the material is new, **how to apply it is still an open question**, and the company is seeking downstream application partners.

Sources:

- https://kxjst.jiangsu.gov.cn/art/2026/6/29/art_82538_11796235.html
- https://kxjst.jiangsu.gov.cn/art/2026/7/6/art_82539_11799463.html

This is closer to the project's latent-connection doctrine than a mature product looking for more sales:

```text
RESOURCE EXISTS
+
OWNER CAN DESCRIBE THE RESOURCE
+
VALUABLE APPLICATION CONNECTION IS NOT YET SETTLED
```

### What is actually measured

This is not only a narrative about “future material.”

Public Xuzhou / Nanjing University material reports:

- stable preparation below 10 nm and about 5 nm for metal-cluster powders;
- hundred-gram-scale W and Ni cluster powders;
- a W-Ni-Fe powder-metallurgy sheet with tensile strength improved by nearly 20%;
- atomic-scale Ni powder reducing a representative engine-casing repair process from about 1200 C to below 1000 C.

Sources:

- https://www.nju.edu.cn/info/1056/463241.htm
- https://www.nju.edu.cn/info/1056/474691.htm
- https://www.nju.edu.cn/info/1056/409491.htm

So the resource side is real enough to observe.

### What we must *not* do

Do **not** jump from:

```text
low-temperature processing property
+
Xuzhou has remanufacturing
=
atomic powder opportunity
```

That would recreate the exact pre-#167 mistake.

XCMG Mining Machinery does publicly report real fatigue, short-life, replacement-cost and lightweight-versus-strength pains. But the same 2026 expert-enterprise event already connected XCMG with an expert team using structural simulation, fatigue optimization, new materials and sensing.

Source:

- https://kxjst.jiangsu.gov.cn/art/2026/6/29/art_82538_11796235.html

Therefore XCMG's pain is only an **adjacent cost-side signal**, not proof that Guoji powder is the missing connection.

### Current state

`RCL-003A-GUOJI-ATOMIC-CLUSTER-POWDER = MEASURED_RESOURCE_EXISTS / APPLICATION_PORTFOLIO_UNRESOLVED / BUYER_COST_UNPROVEN`

### The next decisive evidence

Before any field contact, public research should narrow one industrial task to:

1. current incumbent material/process;
2. current temperature / stress / strength / life / cost limit;
3. named actor paying that cost;
4. exact cluster-powder property that could alter the limit;
5. a coupon/sample experiment;
6. acceptance metric known before the test.

Only then should human validation capital be spent.
