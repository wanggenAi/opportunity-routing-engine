# Source Code

Application/product code still waits for repeated commercial evidence.

The repository now permits **evidence-pipeline code** when it automates a repeated research or validation bottleneck without pretending that code proves demand.

Current first module:

- `opportunity_ranker.py` — implements the canonical 100-point scorecard and hard-gate discipline. A high score cannot bypass `UNKNOWN` or `FAIL` gates.

Allowed pre-PMF automation includes:

- evidence record validation;
- scoring and ranking;
- provenance checks;
- experiment lifecycle handling;
- deterministic document consistency checks used inside a paid/manual validation workflow.

Broad SaaS/product automation remains blocked until repeated paid transactions justify it.
