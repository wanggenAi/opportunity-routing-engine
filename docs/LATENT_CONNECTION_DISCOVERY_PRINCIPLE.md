# Latent Connection Discovery — Constitutional Principle

Status: `CONSTITUTIONAL / LOCKED`

Effective: 2026-09-17

Parents:
- `docs/LATENT_VALUE_DOCTRINE.md`

This principle clarifies the upstream meaning of value formation. It does not create a new ontology, business vertical or software subsystem.

## 1. The connection is discovered before it is designed

The repository's highest-value object is not merely Resource A, Resource B, a Need, a supplier or a product idea. It is the **relationship through which previously stranded value can begin to flow**.

But the system must distinguish two fundamentally different operations:

```text
CONNECTION INVENTION
!=
CONNECTION DISCOVERY
```

`CONNECTION INVENTION` begins with a plausible story:

```text
A exists
+
B exists
+
we can imagine that A and B might help each other
→ design an exchange
→ ask reality whether the idea works
```

That is permitted only as exploratory reasoning. It is not sufficient for formation promotion and it is not the preferred use of scarce human field energy.

`CONNECTION DISCOVERY` begins with reality already exerting directional pressure:

```text
STATE / ENVIRONMENT CHANGE
→ RESOURCE OR CAPABILITY REMAINS / MOVES / BECOMES UNDERUSED
→ ANOTHER ACTOR BEARS A REPEATED COST / DEFICIT / WORKAROUND
→ PARTIAL, INFORMAL, ADJACENT OR SUBSTITUTE FLOWS APPEAR
→ CURRENT ROUTE FAILS / IS TOO COSTLY / TOO RIGID / TOO LOW-TRUST
→ THE SAME VALUE GRADIENT REAPPEARS
→ LATENT CONNECTION BECOMES EVIDENCE-BOUND
```

The system's job is therefore:

> **Discover latent connections that reality is already trying to form, then reduce the friction that prevents those connections from becoming accepted value flow.**

中文定义：

> **发现现实正在形成、但尚未显现的连接；不是凭空创造连接，而是识别社会变化、资源势差、真实行为与既有绕行路径已经共同指向的价值通道，再以最小干预使其显现。**

## 2. “Natural connection” is an engineering claim, not metaphysical certainty

The repository may use the intuition of `顺势 / 自然形成` to guide discovery, but software must translate that intuition into falsifiable evidence.

A `LATENT CONNECTION` means:

> an evidence-bound relationship between real-world nodes for which observable state changes, resource gradients, actor behavior and current-route friction indicate that value is already attempting to cross the boundary, even though no mature exchange structure exists yet.

Therefore:

```text
COMPLEMENTARITY != LATENT_CONNECTION
PLAUSIBLE STORY != LATENT_CONNECTION
SHARED TREND != LATENT_CONNECTION
PUBLIC SOCIAL PROBLEM != LATENT_CONNECTION
ONE WORKAROUND != REPEATABLE_CONNECTION
LATENT_CONNECTION != ACCEPTED_EXCHANGE
```

The system must not claim that a connection “should exist” merely because an LLM, founder or analyst can imagine mutual benefit.

## 3. Canonical discovery chain

Latent-connection discovery is downstream of causal-depth discovery. The first visible pain is not assumed to be the governing friction.

The constitutional upstream chain is:

```text
WORLD / STATE CHANGE
        ↓
ACTOR + OBJECTIVE ENDOWMENT / STATE / BEHAVIOR
        ↓
SURFACE PHENOMENON / SURFACE FRICTION
        ↓
COMPETING LATENT / UNFORMED OUTCOME HYPOTHESES
        ↓
RECURSIVE CAUSAL DESCENT
        ↓
COMPETING STRUCTURAL FRICTION HYPOTHESES
        ↓
DISCRIMINATING EVIDENCE / FALSIFIERS / CONTRADICTION SEARCH
        ↓
DECISION-USEFUL CAUSAL FRONTIER
        ↓
EVIDENCED STRUCTURAL FRICTION
        ↓
COMPLEMENTARY WORLD-NODE SEARCH
        ↓
STRUCTURAL COMPLEMENTARITY
        ↓
CONNECTION-PRESSURE EVIDENCE
        ↓
PARTIAL FLOW / WORKAROUND / SUBSTITUTE / ADJACENT PRECEDENT
        ↓
OBSERVED MISSING EDGE BETWEEN NODES
        ↓
LATENT CONNECTION HYPOTHESIS
        ↓
CONTRADICTION SEARCH
        ↓
ONLY THEN: COUNTERFACTUAL EXCHANGE MECHANICS
        ↓
CHEAPEST DECISIVE REALITY CONFIRMATION
        ↓
ONLY IF SUPPORTED: NEED / RESOURCE / BLOCKER / PAYER / COMMITMENT
        ↓
ROUTING / ACCEPTANCE / SETTLEMENT / REPEAT
```

The important change is ordering:

```text
OLD RISKY ORDER:
COMPLEMENTARY NODES
→ DESIGN CONNECTION
→ SEND HUMAN TO FIND OUT

CANONICAL ORDER:
COMPLEMENTARY NODES
→ DISCOVER CONNECTION PRESSURE
→ IDENTIFY THE MISSING EDGE
→ DESIGN ONLY THE MINIMUM EXECUTION MECHANICS
→ USE HUMAN REALITY CONTACT AS THE LAST DECISIVE TEST
```

## 3A. Structural friction is not the missing edge

These two concepts must not collapse into one another.

```text
STRUCTURAL FRICTION
=
why an Actor cannot reach its latent desired state under current structures

MISSING EDGE
=
why identified complementary nodes cannot convert their complementarity into normal value flow
```

A visible cost may reveal neither one directly. The engine may need to infer the deeper structural friction first, corroborate it, then search which complementary nodes are relevant. Only after those nodes are identified can the inter-node missing edge be meaningfully investigated.

Therefore:

```text
SURFACE COST != ROOT CAUSE
ROOT-CAUSE HYPOTHESIS != EVIDENCED STRUCTURAL FRICTION
STRUCTURAL FRICTION != MISSING EDGE
```

## 4. Connection-pressure evidence

Before a formation may become `VALIDATION_READY`, the repository must preserve at least one explicit `CONNECTION_PRESSURE` evidence record tied to the proposed nodes and relationship.

Useful connection-pressure evidence includes one or more of the following, preferably corroborated across independent sources:

- repeated actor workarounds that already approximate the proposed relationship;
- informal/manual/relationship-based exchange already occurring at small scale;
- repeated failed attempts to cross the same boundary;
- repeated search, substitution, referral or coordination behavior connecting the two sides indirectly;
- a shared external change that simultaneously increases stranded value on one side and costly deficit/pressure on another;
- adjacent markets, geographies or historical periods where the same underlying relationship formed after a comparable friction reduction;
- repeated events showing value already moves through a more expensive, slower, lower-trust or institutionally awkward route;
- observable bypass behavior demonstrating that actors are already spending time, money, reputation or coordination effort to obtain the missing connection.

This evidence does not prove willingness to pay or transactionability. It proves only that the connection hypothesis is grounded in **directional reality pressure rather than free-form combination**.

## 5. The missing edge must be observed, not invented

The engine must separately identify why the connection has not become a normal flow.

Examples include:
- trust;
- permission / authority;
- information asymmetry;
- search cost;
- packaging / interface mismatch;
- granularity mismatch;
- timing mismatch;
- acceptance / quality uncertainty;
- liability;
- settlement;
- coordination cost;
- institutional boundary;
- geography / language / context boundary.

But:

```text
MISSING EDGE HYPOTHESIS != OBSERVED MISSING EDGE
```

A missing edge becomes evidence only when behavior, failed attempts, current workarounds, transaction history, field truth or another attributable source exposes it.

## 6. Counterfactual Exchange Design is downstream mechanics

Historical repository language uses `COUNTERFACTUAL EXCHANGE DESIGN`. That operation remains useful, but its constitutional role is narrowed.

It may answer:

> **Given an already evidenced latent connection, what minimum roles, permissions, interfaces, incentives, trust, acceptance and settlement mechanics would let the value flow with less friction?**

It must no longer answer:

> “Which unrelated resources should we connect because the combination sounds valuable?”

Therefore:

```text
LATENT CONNECTION DISCOVERY
PRECEDES
COUNTERFACTUAL EXCHANGE DESIGN
```

and:

```text
COUNTERFACTUAL EXCHANGE DESIGN
!=
EVIDENCE THAT THE CONNECTION EXISTS
```

A novel mechanism may still be designed. The **relationship pressure** it intends to serve must be discovered first.

## 7. Human attention is validation capital

Founder time, field visits, calls, introductions and counterpart attention are scarce resources.

The system must not use humans as the default search algorithm for every plausible combination.

```text
HUMAN OUTREACH != PRIMARY DISCOVERY SENSOR
FIELD VISIT != SUBSTITUTE FOR CONNECTION EVIDENCE
EMAIL SENT != VALIDATION
```

The preferred sequence is:

```text
MACHINE / DOCUMENT / MARKET / BEHAVIOR SENSING
→ CROSS-SOURCE CONNECTION PRESSURE
→ RANKED LATENT CONNECTION
→ IDENTIFY THE SINGLE MOST UNCERTAIN DECISIVE FACT
→ TARGETED HUMAN CONTACT / FIELD OBSERVATION
```

Human action is the surgeon's final cut: precise, bounded and aimed at the weakest unresolved truth.

The weakest unresolved truth may be a structural-causality question before a public missing edge is fully established. When broad sensing has already narrowed the uncertainty to one causal fact, the hypothesis may be marked `DECISIVE_UNKNOWN / PROBE_ELIGIBLE`. This does not make human outreach the primary discovery sensor and does not promote the candidate.

A field probe should ask about recent concrete events, current workarounds, failed attempts, cost, approval authority and the narrow causal uncertainty—not ask actors to endorse an abstract idea.

## 8. Promotion discipline

A formation without `CONNECTION_PRESSURE` may remain:
- observation;
- resource-psychology disequilibrium hypothesis;
- latent-value formation hypothesis;
- complementarity hypothesis.

It must not become `VALIDATION_READY` merely because:
- the nodes exist;
- they look complementary;
- a counterfactual exchange is well written;
- a social problem is important;
- an LLM assigns high confidence;
- the founder is willing to test it.

The `VALIDATION_READY` state means:

> the system has enough objective evidence that reality is already pushing toward this connection to justify spending scarce human/external validation capital on the remaining decisive uncertainty.

It still does not mean demand, willingness to pay, transaction, profitability or repeatability.

## 9. Anti-overfit / anti-dogma boundary

This principle must not become a fixed taxonomy of what a “natural” connection looks like.

New technology can create genuinely new affordances before strong behavior traces exist. Such combinations may be kept as exploratory observations, but they remain below `VALIDATION_READY` until connection-pressure evidence appears.

Do not force every future phenomenon into today's examples. Preserve residuals and contradictions.

The goal is not to prohibit invention. The goal is to prevent invention from masquerading as discovery.

## 10. Governing invariants

Additional upstream invariants:

```text
SURFACE PHENOMENON != STRUCTURAL FRICTION
STRUCTURAL FRICTION HYPOTHESIS != EVIDENCED STRUCTURAL FRICTION
STRUCTURAL FRICTION != MISSING EDGE
BUYER COST FIRST != CONSTITUTION
```


```text
CONNECTION_INVENTION != CONNECTION_DISCOVERY
COMPLEMENTARITY != LATENT_CONNECTION
PLAUSIBLE_SURPLUS != CONNECTION_PRESSURE
CONNECTION_HYPOTHESIS != CONNECTION_PRESSURE_EVIDENCE
MISSING_EDGE_HYPOTHESIS != OBSERVED_MISSING_EDGE
COUNTERFACTUAL_EXCHANGE != LATENT_CONNECTION_EVIDENCE
LATENT_CONNECTION != ACCEPTED_EXCHANGE
HUMAN_OUTREACH != PRIMARY_DISCOVERY_SENSOR
FIELD_CONFIRMATION != DEMAND
DEMAND != WILLINGNESS_TO_PAY
WILLINGNESS_TO_PAY != TRANSACTION
TRANSACTION != REPEATABLE_MODEL
UNKNOWN != PASS
```

> **我们不以人的想象规定资源应该怎样结合，而是先看现实本身正在把哪些 Actor、资源、能力与压力推向同一条价值通道。系统的智能首先用于发现这种“已经在发生但尚未完成”的连接：共同变化、资源势差、重复绕行、局部交换、替代行为和真实阻塞都在留下痕迹。只有这些痕迹收敛以后，才设计最小的连接机制，并把人的时间、信誉与现场行动用于最后一个关键未知量。不是创造一条漂亮的路，再问现实愿不愿意走；而是先发现现实已经踩出来的小径，再决定是否值得把它变成路。**

Compatibility note: legacy persisted evidence labeled `STRANDING_BARRIER` is normalized to canonical `MISSING_EDGE`. The legacy term must not re-enter new canonical ontology or state transitions.
