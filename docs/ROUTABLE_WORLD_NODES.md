# Routable World Nodes

Status: `CANONICAL / CASE-NEUTRAL`

## Purpose

The routing engine must not collapse the world into people. Human beings are only one kind of node through which value, information, access, capability, capacity or authority may flow.

The engine must discover and reason about heterogeneous world nodes without turning these families into fixed business categories.

## Canonical node families

```text
PERSON / INDIVIDUAL
GROUP / COMMUNITY
ORGANIZATION / INSTITUTION
PHYSICAL RESOURCE / ASSET
CAPABILITY / PROCESS
CHANNEL / NETWORK
INFORMATION / DATA SOURCE
SPACE / LOCATION
EQUIPMENT / INFRASTRUCTURE
INVENTORY / CAPACITY
CAPITAL / BUDGET
AUTHORITY / LICENSE / ACCESS RIGHT
SOFTWARE / AI / API
CONTRACT / RULE / STANDARD
DEMAND STREAM / EVENT FLOW
TRUST / REPUTATION / RELATIONSHIP
```

These are observation/routing families, not opportunity categories and not a scan quota.

## Node truth

```text
EXISTS
!=
OBSERVED
!=
ACCESSIBLE
!=
OPTIONED
!=
CONTROLLED
!=
TRANSACTIONABLE
```

For any node, record only what evidence supports: controller, current state, possible underuse/misalignment, access basis, permission boundary, availability window, activation cost, expected counterparty gain, required evidence, acceptance rule and replacement candidates.

People are actors, not inventory. Human time, knowledge, trust, reputation or access become routable resources only under voluntary and explicit conditions.

## Collective structure

A group or organization may create value that no member owns alone through pooled trust, aggregate demand/capability, legitimacy, recurring access, procedures, shared infrastructure, authority or event flow.

```text
GROUP VALUE != SUM(INDIVIDUAL VALUE)
ORGANIZATION CAPABILITY != EMPLOYEE CAPABILITY
```

## Non-human nodes and sensors

Physical or digital resources may be first-class nodes without being forced into a labor-market model.

Reality sensing may come from:

```text
PERSON
GROUP / COMMUNITY
ORGANIZATION
MARKETPLACE
PROCUREMENT FEED
PRICE SERIES
EQUIPMENT TELEMETRY
ERP / CRM EVENT
PUBLIC RECORD
CUSTOMER-SERVICE QUEUE
LOGISTICS FLOW
SOCIAL / INDUSTRY DISCUSSION
SOFTWARE / AI AGENT
```

Always ask what change was observed, through which source/node, with what provenance and freshness, and what the evidence does and does not prove.

## Clean-slate boundary

Node families are reusable cognition. They must not reintroduce pre-reset commercial cases.

```text
NODE FAMILY != CANDIDATE
EXAMPLE POSSIBILITY != ACTIVE CASE
SOURCE NODE != SEARCH PRIOR
```

The next formation must arise from current evidence under the active Attraction Field epoch.
