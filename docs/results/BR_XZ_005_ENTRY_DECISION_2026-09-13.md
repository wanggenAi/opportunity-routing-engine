# BR-XZ-005 Entry Decision — 2026-09-13

Status: `COMPOSITE SPLIT -> 005A AFFILIATION ROUTE FIRST / 005B RESOURCE-OFFICE ROUTE SECOND`

## Architectural correction

`BR-XZ-005` was previously modeled as one combined node:

`Jiangsu Huaihai Technology Property Rights Exchange Center + CUMT Science Park Technology-Manager Office`.

This is too coarse.

Xuzhou Daily explicitly describes them as **two platforms** in the city's recurring technology-demand discovery mechanism. In the same real case:
- Wang Yingping is described as a technology manager **affiliated with Jiangsu Huaihai Technology Property Rights Exchange Center**;
- she then uses the **CUMT Science Park technology-manager office's expert/result databases** to match the enterprise problem to a university team.

Source:
- https://szb.cnxz.com.cn/xzrb/pad/con/202607/13/content_52654.html

Therefore:

```text
BR-XZ-005A = Jiangsu Huaihai Technology Property Rights Exchange Center
             -> observed affiliation / legitimacy / transaction context

BR-XZ-005B = CUMT Science Park Technology-Manager Office
             -> expert/result network / technology-transfer office / professional practice
```

Do not assume one institution must supply every layer of backing.

## Current decision

Do **not** pay for a technology-manager training certificate merely to create status.

The cheapest correct sequence is now:

```text
1. Use the live Jiangsu Technology Property Rights Exchange Market registration route
2. Verify technology-manager identity application requirements
3. Validate BR-XZ-005A first: current external affiliation / project-cooperation rules
4. Validate BR-XZ-005B separately: external participation, expert/result access and supervised real-case rules
5. Only take paid training if it materially unlocks identity approval, affiliation, supervised cases or required competence
6. Only after an observable institutional commitment exists, use that role to access enterprise / university actors
```

## Certificate decision

Current evidence does **not** prove an initial training certificate is the first required gate for Jiangsu technology-manager identity application.

Therefore:

```text
TRAINING = POSSIBLE CAPABILITY / NETWORK ACCELERATOR
TRAINING != FIRST PROVEN GATE
TRAINING != AFFILIATION
TRAINING != ENDORSEMENT
```

Pay for training only if:
- identity approval requires it;
- 005A/005B requires or strongly prefers it for affiliation/project cooperation;
- or a specific class materially unlocks supervised real-project access.

## What counts as real backing

Sufficient examples:
- signed affiliation/project-cooperation agreement;
- accepted onboarding with defined rights;
- assignment to a real supervised case;
- acceptance of an externally discovered case into institutional workflow;
- formal introduction under the institution's role.

Insufficient:
- training attendance;
- certificate;
- platform registration or identity application alone;
- public telephone/address;
- informal encouragement.

## Current route verdict

```text
BR-XZ-005A = VALIDATE FIRST
BR-XZ-005B = VALIDATE SECOND / PARALLEL
```

This route remains a legitimacy/backing wedge for the broader latent-value engine. It must not redefine the project into conventional technology brokerage.

The deeper architectural lesson is that backing can itself be **composed**:

```text
AFFILIATION / LEGITIMACY
+ TRANSACTION INFRASTRUCTURE
+ EXPERT / RESULT NETWORK
+ INDUSTRY ACCESS
+ VALIDATION CAPABILITY
```

Different actors may provide different layers, and the orchestrator's job is to connect them lawfully where each actor has a visible benefit.
