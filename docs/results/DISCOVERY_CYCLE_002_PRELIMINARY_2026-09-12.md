# Discovery Cycle 002 — Xuzhou Hidden-Value Research Reset

Date: 2026-09-12
Status: `RESET / CORE LATENT-VALUE SEARCH ONLY`
Constitutional parent: `docs/LATENT_VALUE_DOCTRINE.md`

The previous preliminary ranking over-weighted visible project activity, near-term payer paths and operator skill fit. That created a drift toward explicit-demand execution.

This reset removes that first-found privilege.

## 1. Locked distinction

```text
EXPLICIT_DEMAND_EXECUTION
= someone already knows the task/value and mainly needs execution/matching

LATENT_VALUE_ACTIVATION
= value is not yet recognized, packaged, combined or operating as a market object
```

Only the second class is eligible for the **core Cycle 002 discovery ranking**.

The digital-transformation service-provider backend route remains a valid downstream commercial experiment, but it is no longer a core discovery winner.

## 2. Discovery order — unchanged

```text
MACRO
→ MONEY FLOW
→ PSYCHOLOGY
→ BEHAVIOR
→ INDUSTRY STRUCTURE
→ ACTOR STATE / ENDOWMENT
→ HIDDEN OR UNDERRECOGNIZED VALUE

```

Operator fit and monetization convenience are applied only after the latent-value thesis exists independently.

## 3. Current hidden-value search targets

These are **search targets**, not verified opportunities.

### HV-01 — Tacit industrial knowledge that is still person-bound

Search question:

> Which experienced technicians, operators, maintenance staff, service engineers or managers possess repeatable decision knowledge that their organization still treats only as personal experience?

Possible latent value:
- fault-diagnosis logic;
- machine sound/behavior interpretation;
- repair sequencing;
- supplier/part substitution knowledge;
- commissioning heuristics;
- acceptance/debugging knowledge;
- process-exception handling.

Why it may be hidden:
- knowledge is embedded in a person rather than represented as an asset;
- value appears only when another actor faces the same uncertainty;
- there may be no packaging, proof, rights or settlement structure.

Complementary actors to search:
- smaller factories without equivalent senior knowledge;
- new technicians;
- service networks with repeated diagnosis uncertainty;
- equipment users facing expensive downtime.

Transformation mechanisms to test:
`extract → verify → standardize → callable decision unit → bounded acceptance/payment`.

### HV-02 — Operational data that is collected but economically dormant

Search question:

> Which factories/service organizations already possess logs, repair histories, exception records, quality records, spare-part histories or customer-service data that are stored but do not change decisions?

Possible latent value:
- failure-pattern intelligence;
- preventive-maintenance cues;
- spare-part demand prediction;
- service-quality benchmarking;
- recurring exception knowledge.

The asset is not `data` by itself. The value appears only when data can reduce another actor's decision cost, downtime, error or inventory risk.

Transformation mechanisms:
`clean → contextualize → verify → derive decision output → measure avoided cost`.

### HV-03 — Fragmented small demand that becomes valuable only when aggregated

Search question:

> Which Xuzhou SMEs/merchants/operators repeatedly buy small quantities, small technical tasks, maintenance, consumables, logistics or services at poor terms because each actor is too small to matter individually?

Possible latent value:
- the **aggregate demand itself** becomes a resource;
- batch demand may unlock better price, service level, delivery route or specialist attention.

Complementary actors:
- suppliers with minimum efficient order sizes;
- specialists who ignore tiny jobs individually;
- logistics/resources with fixed setup costs.

Transformation mechanism:
`observe repeated fragments → standardize requirement → aggregate → create credible commitment → negotiate/route → settle`.

### HV-04 — Idle or badly scheduled local capacity that owners do not treat as a product

Search question:

> Where do equipment, venues, technicians, vehicles, workshops, channels, service desks or production/service time windows sit partially idle while adjacent actors pay for scarcity elsewhere?

Possible latent value:
- unused shifts/hours;
- off-peak space;
- spare machine capacity;
- return logistics;
- spare service slots;
- technical people between projects.

Important boundary:
`resource exists != spare capacity`; underuse must be observed.

Transformation mechanism:
`measure underuse → define conditional availability → create callable slot → match complementary timing/geography → acceptance/settlement`.

### HV-05 — Relationships, trust and installed access that are not monetized as standalone assets

Search question:

> Which actors already possess trusted access to factories, merchants, communities, equipment owners, customers or supply-chain nodes but use that access only for one narrow purpose?

Possible latent value:
- lower acquisition cost;
- lower verification cost;
- faster adoption;
- trusted introduction plus accountability;
- installed-base service access.

This is not a license to sell personal relationships. Rights, consent, confidentiality and conflicts must be explicit.

Transformation mechanism:
`permission → bounded adjacent use → trust-preserving interface → measurable outcome → transparent economics`.

### HV-06 — Uneven utilization in Xuzhou service/experience scenes

Search question:

> Where do merchants, venues, experiences or service resources have valuable but empty time/space while visitor or local demand is concentrated elsewhere in time, channel or itinerary?

Possible latent value:
- empty weekday capacity;
- unused private rooms/venues;
- fragmented experiences not discoverable as a coherent route;
- outside-city demand that does not reach secondary merchants.

Transformation mechanism:
`observe utilization gap → aggregate complementary demand → package route/event/use case → attribute incremental utilization`.

This field remains core only if the value is hidden/underutilized. Generic merchant lead generation is `EXPLICIT_DEMAND_EXECUTION` and must be downgraded.

## 4. What is deliberately removed from the core ranking

The following may still make money, but do not qualify as core latent-value discoveries by themselves:

- a digital service provider already asking for outsourced programmers;
- a factory already publishing a software requirement;
- a company explicitly asking for AI automation;
- a merchant already buying customer acquisition;
- an RFQ/procurement notice with an existing specification.

These are classified as:

```text
candidate_class = EXPLICIT_DEMAND_EXECUTION
```

They may be retained for cash-flow experiments but must not define what the engine searches for.

## 6. Immediate research priority

Do **not** rank by which one fits the operator's IT background.

First acquire evidence for:

1. `HV-01` person-bound industrial knowledge;
2. `HV-03` fragmented demand aggregation;
3. `HV-04` genuinely underused local capacity;
4. `HV-02` dormant operational data;
5. `HV-05` trust/access resources;
6. `HV-06` uneven service/experience utilization.

Priority can change as evidence arrives.

## 7. First decisive field questions

### For HV-01
Find real examples where loss/unavailability of one experienced person creates delay, downtime, quality risk or repeated dependence. Determine whether the knowledge can be extracted legally and whether another actor would value the result.

### For HV-03
Find at least three independent actors repeatedly purchasing the same class of small input/service under weak economics. Test whether aggregation materially changes price, response time or supplier attention.

### For HV-04
Observe actual utilization, not listings. Measure idle time/capacity and identify a complementary actor paying for scarcity of the same function elsewhere.

### For HV-02
Find data already collected but not operationally used. Identify a repeated decision whose cost can be reduced by transforming that data.

## 8. Current conclusion

There is **no canonical business winner**.

Cycle 002 is now correctly scoped as a search for hidden assets, hidden deficits and unrealized complementarities in Xuzhou.

The next valid output is not `which software service should the operator sell?`.

It is:

> **Which real Actor owns something whose value is currently invisible or trapped, which other Actor becomes better off if that value is transformed, and what mechanism can unlock the exchange?**
