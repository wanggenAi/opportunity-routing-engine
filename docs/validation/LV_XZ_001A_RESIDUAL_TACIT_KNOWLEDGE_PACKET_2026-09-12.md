## 1. Correction to the original thesis

The broad thesis `veteran technicians possess uncodified valuable knowledge` is too weak and is contradicted by part of the public evidence.

Xuzhou/XCMG already has:
- skill-master studios;
- mentor/apprentice systems;
- strong vocational training;
- conversion of frontline experience into process standards;
- intelligent-manufacturing retraining;
- supply-chain and overseas skill training.

Therefore the only core latent-value question that remains legitimate is:

> **After existing SOPs, standards and training are accounted for, is there still a measurable residual expert judgment layer that is useful, rights-clearable and reproducible?**

If not, kill the candidate.

## 3. Core experiment: Residual Knowledge Gap Test

### Step A — choose one bounded task

Requirements:
- employer explicitly authorizes the test;
- non-confidential or sandbox/historical cases;
- current SOP/training material exists;
- outcome is measurable;
- no safety-critical live intervention;
- enough cases exist to compare results.

Good task shapes may include, only after authorization:
- recognizing a machining anomaly from permitted signals;
- distinguishing a small set of non-sensitive failure patterns;
- choosing among approved troubleshooting branches;
- interpreting a permitted combination of sound/vibration/visual/process cues;
- identifying likely quality/process deviation on historical examples.

### Step B — establish the baseline

Before interviewing an expert, collect the current official baseline:
- SOP;
- training material;
- checklists;
- decision tree;
- standard sensor thresholds;
- existing examples/cases.

Record how a qualified non-expert performs using this material.

Metrics may include:
- first-pass accuracy;
- time to decision;
- false positive / false negative rate;
- number of escalation steps;
- rework or diagnostic time.

### Step C — observe expert delta

Give matched cases to an authorized expert.

Do **not** ask `What are your secrets?`

Ask process questions tied to the case:
- What did you notice first?
- What signal changed your hypothesis?
- What alternatives did you eliminate?
- Which cue combinations matter rather than one threshold?
- When does the standard rule fail?
- What would make you escalate rather than decide?

Capture only information explicitly cleared by the employer/expert.

### Step D — isolate residual cues

A cue is a candidate residual asset only if all are true:

```text
not already represented in baseline material
+ expert actually used it
+ it explains measurable performance delta
+ rights allow capture/use
+ it can be stated without exposing prohibited confidential information
```

Otherwise it is not a latent resource.

### Step E — reproducibility test

Give the extracted cue/rule/case module to another qualified non-expert who did not observe the expert session.

Pass only if the module reproduces a meaningful portion of the expert improvement on new matched cases.

This distinguishes:

```text
EXPERT IS GOOD
```

from:

```text
EXPERT HOLDS TRANSFERABLE RESIDUAL KNOWLEDGE
```

### Step F — complementary value test

Only after the residual module passes internally, test one authorized complementary context:
- training cohort;
- supply-chain technical team;
- service team;
- evaluation/benchmark setting;
- industrial AI/evaluation team with explicit rights.

Measure incremental value against the existing training/SOP baseline.

## 4. Mandatory rights questions

Before any extraction/reuse, obtain explicit answers:

1. Is the knowledge created in employment and owned/controlled by the employer?
2. Is any part a trade secret or confidential production method?
3. Can the expert discuss it outside the original work context?
4. Can anonymized/abstracted cases be retained?
5. Who owns a derived rule, case set, annotation or training module?
6. What audiences/uses are allowed?
7. Is compensation required for expert and/or employer?
8. Can the module be reused, or only delivered as a one-time service?
9. What review/approval is required before external use?

Any ambiguous answer remains `UNKNOWN` and blocks promotion.

## 6. PASS / KILL

### PASS to a stronger latent-value state only if

- an expert delta over current training/SOP is measured;
- at least one useful residual cue can be articulated;
- the cue is rights-clearable;
- another person using the module reproduces meaningful improvement;
- a complementary actor gets measurable incremental value;
- the value does not require the original expert every time.

### KILL or downgrade if

- existing standards/training already explain performance;
- expert advantage is mostly motor skill/personal talent that cannot be transferred;
- cues are confidential/trade-secret and cannot be authorized;
- extracted cues fail reproducibility;
- complementary actors gain no measurable increment;
- master-studio/internal training already delivers the same value more efficiently;
- economics do not cover extraction, verification and rights cost.
