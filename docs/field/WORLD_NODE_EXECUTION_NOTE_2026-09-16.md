# World-Node Execution Note — 2026-09-16

Status: `P0 FIELD BINDING`

Parent: `docs/field/ROUTABLE_WORLD_NODES_2026-09-16.md`

The active field program must not search only for a person who can introduce, scout or execute.

For every real friction, search the surrounding graph for the cheapest legitimate node that changes the state:

```text
PERSON
GROUP
ORGANIZATION
RESOURCE / ASSET
CHANNEL / NETWORK
DATA / INFORMATION
SPACE / EQUIPMENT / CAPACITY
AUTHORITY / ACCESS RIGHT
CAPITAL / BUDGET
SOFTWARE / AI
RECURRING DEMAND / EVENT FLOW
TRUST / REPUTATION
```

Examples of equivalent P0 questions:

```text
Is there a person who already sees the problem?
Is there a group whose members repeatedly experience it?
Is there an organization whose mission already requires solving it?
Is there an idle physical/digital resource that changes the economics?
Is there a channel with recurring access to the relevant actors?
Is there a data/event stream that reveals the friction without manual interviews?
Is there a license, contract, institutional right or trust relationship that unlocks the route?
Is there an existing budget/demand stream that can fund the outcome?
```

The next route should therefore be selected by **node economics and controllability**, not by occupational title.

A technology manager remains only one candidate node among many.
