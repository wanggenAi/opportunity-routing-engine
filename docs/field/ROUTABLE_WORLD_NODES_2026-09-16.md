## Purpose

The routing engine must not collapse the world into people.

Human beings are only one kind of node through which value, information, access, capability, capacity or authority may flow.

The engine must be able to discover, option, compose and route **heterogeneous world nodes**.

## Group / organization rule

A group or organization is not equivalent to the people inside it.

Its value may arise from structure that no single member owns alone, such as:
- pooled trust;
- aggregated demand;
- aggregated capability;
- collective bargaining power;
- institutional legitimacy;
- recurring member access;
- operating procedures;
- distribution;
- shared infrastructure;
- governance / certification / authority;
- repeated event flow.

Therefore:

```text
GROUP VALUE != SUM(INDIVIDUAL VALUE)
ORGANIZATION CAPABILITY != EMPLOYEE CAPABILITY
```

## Resource rule

A physical or digital resource can be a first-class routing node even when no person performs an active service.

Examples:

```text
IDLE MACHINE
→ OPTION CAPACITY WINDOW
→ MATCH JOB SPECIFICATION
→ PRICE / QA / DELIVERY RULE
→ TRANSACTION

EMPTY SPACE
→ DEFINE ALLOWED SCENARIOS
→ MATCH TEMPORARY USE
→ APPROVAL / LIABILITY / SETTLEMENT
→ UTILIZATION

DATA / API
→ VERIFY RIGHTS
→ DEFINE INPUT / OUTPUT
→ ROUTE INTO DECISION OR DELIVERY PROCESS
```

The system should not anthropomorphize such nodes or force them into a labor-market model.

The founder should not become the universal sensor, owner, salesperson or executor.

The operating model is:

```text

  people
  groups
  organizations
  resources
  channels
  assets
  data
  authority
  capital

      ↓
```
