## 1. Why this bridge exists

The repository already had two correct but partly separate capabilities:

1. observe objective actor state, endowments, underuse and complementary resources;
2. observe changing `PERCEPTION / MOTIVE / BEHAVIOR` with provenance and corroboration.

The missing bridge was the explicit reasoning boundary between them.

The engine must not wait only for a person or enterprise to publish an explicit need. It should also be able to ask:

> **Given what an actor objectively has, what has changed in that actor's state, how perception/motive/behavior is changing, and what complementary nodes exist elsewhere, is there a falsifiable exchange structure that does not yet exist but could create incremental value?**

This is not demand creation by imagination. It is evidence-bound **latent value formation**.

## 3. Resource–Psychology Disequilibrium

A useful discovery pattern exists when an actor's objective endowments and current ability/desire to use those endowments become misaligned.

Illustrative structures:

```text
HAS MONEY
+ MORE FREE TIME
+ NEW DESIRE FOR AUTONOMY / EXPERIENCE
+ WEAK MODERN-DIGITAL ROUTE
→ possible latent outcome, not yet a product
```

```text
HAS DEEP INDUSTRY EXPERIENCE
+ RETIRES FROM FULL-TIME ROLE
+ STILL VALUES CONTRIBUTION / RELEVANCE
+ DOES NOT WANT ANOTHER FULL-TIME JOB
→ potentially callable bounded expertise, if rights/proof/acceptance can be designed
```

```text
HAS DIGITAL / AI EXECUTION CAPABILITY
+ HAS TIME
+ WEAK TRUST / CLIENT ACCESS / INDUSTRY CONTEXT
→ underused execution resource, not automatically supply
```

The engine then searches for complementary nodes rather than immediately inventing a product.

## 4. What psychology contributes

Psychology is used to explain possible direction of state transition:

```text
STATE CHANGE
→ changed perception
→ changed motive
→ observed adaptation behavior
```

It can help infer why an objectively available resource is not being used in the old way and what classes of outcomes may become newly valued.

It cannot prove demand.

```text
PSYCHOLOGY SIGNAL != DEMAND
MOTIVE HYPOTHESIS != WILLINGNESS TO PAY
BEHAVIOR SIGNAL != TRANSACTION
SOCIAL SALIENCE != POPULATION SHARE
```

`PsychologySnapshot` evidence must retain provenance from the canonical tracker. Before this bridge becomes `VALIDATION_READY`, psychology must be tied to the same actor segment and have behavior corroboration. Money corroboration strengthens the hypothesis but is not required merely to decide that a cheap bounded validation is worthwhile.

## 5. Objective evidence remains independent

Psychology may not fill objective evidence gaps.

Validation-ready formation separately requires evidence for:

```text
OBJECTIVE_ENDOWMENT
ORIGIN_STATE
ORIGIN_CHANGE
UNDERUSE_MISALIGNMENT
OBSERVED_BEHAVIOR
COMPLEMENTARY_NODE
STRANDING_BARRIER
```

A viral narrative about retirees, graduates, parents, merchants or another group cannot manufacture an endowment, underuse state or complementary resource.

Likewise:

```text
RESOURCE EXISTS != RESOURCE IS UNDERUSED
UNDERUSED != AVAILABLE
AVAILABLE != OPTIONED
```

These remain downstream resource-control truths.

The node taxonomy stays open. The important fields are the node's observed state, possible contribution, owner/controller and evidence lineage.

## 7. Counterfactual exchange design

The central discovery question is not:

> What existing business should we copy?

It is:

> **If currently separate real-world nodes were connected under explicit roles, incentives, permission, trust and acceptance, could a new exchange create incremental value for all required participants?**

This is a counterfactual until reality accepts it.

```text
COUNTERFACTUAL EXCHANGE != ACCEPTED EXCHANGE
COMPLEMENTARITY != TRANSACTIONABILITY
LATENT VALUE FORMATION != COMMERCIAL OPPORTUNITY
```

The design should explain:
- what state would change;
- which nodes contribute what;
- what the origin actor gains;
- what complementary nodes gain;
- why the exchange is absent today;
- what value the orchestrator adds beyond introduction;
- what cheapest experiment can kill or support the hypothesis.

## 8. Maturity states

```text
OBSERVED_TRANSITION
→ RESOURCE_PSYCHOLOGY_MISALIGNMENT_HYPOTHESIS
→ LATENT_VALUE_FORMATION_HYPOTHESIS
→ COMPLEMENTARITY_HYPOTHESIS
→ VALIDATION_READY
```

### `OBSERVED_TRANSITION`
A state change or psychology signal is visible, but objective resource/state evidence or psychology linkage is incomplete.

### `RESOURCE_PSYCHOLOGY_MISALIGNMENT_HYPOTHESIS`
Objective endowments/state/change and a perception/motive signal coexist, but underuse or behavior linkage is not yet strong enough.

### `LATENT_VALUE_FORMATION_HYPOTHESIS`
Underuse/misalignment and observed behavior are evidenced; a new valued-outcome hypothesis can be stated without claiming a market exists.

### `COMPLEMENTARITY_HYPOTHESIS`
One or more evidenced world nodes could plausibly change the state, and a counterfactual exchange has been designed, but evidence/contradictions remain incomplete.

### `VALIDATION_READY`
All bridge evidence dimensions are present, psychology is behavior-corroborated, complementary nodes are evidenced, the stranding barrier is observed, and no material unresolved contradiction remains.

It means only:

> run the cheapest decisive test.

It does **not** mean payer, paid need, controlled resource, route testability, profitability or scale.

## 9. Contradictions are first-class

The bridge preserves contradiction evidence rather than averaging it away.

Examples:
- another segment already solves the outcome cheaply;
- the apparent underuse disappears when utilization is measured;
- the psychology signal is an algorithmic/social-media artifact;
- public/free provision already solves the outcome;
- complementary actors have no incentive to participate;
- a supposedly new exchange already exists efficiently.

A material unresolved contradiction blocks `VALIDATION_READY`.

## 10. Example — retirement transition × young digital capacity

This is an **example hypothesis**, not a canonical opportunity.

Origin segment may contain:
- newly available time;
- pension/savings for some segments;
- decades of professional/life experience;
- a retirement-driven change in schedule, identity and social structure.

Psychology/behavior sensing may observe:
- desire for autonomy, experience, relevance or connection;
- learning, travel, interest-group, digital-tool or selective continued-work behavior.

Complementary nodes may include:
- younger digital/AI executors with underused capacity;
- trusted communities/institutions;
- spaces;
- software/payment infrastructure;
- SMEs needing bounded expert judgment;
- existing service channels.

The correct next question is not:

> Should we build a senior-training app?

It is:

> Which evidenced combination changes a real state, creates surplus for every required node, and survives a real commitment test?

Possible hypotheses can then be killed or strengthened independently.

## 11. Privacy and dignity boundary

The bridge uses aggregate/segment evidence and non-sensitive actor-state observations where possible.

Do not:
- build unnecessary individual psychographic dossiers;
- infer sensitive personal traits;
- target vulnerable people through hidden manipulation;
- exploit unemployment, aging, loneliness or financial pressure;
- treat people as inert inventory.

People remain `ACTOR`s. Their time, knowledge, capability, trust and access may be resources only under explicit voluntary terms.

## 12. Projection boundary

`src/latent_value_formation.py` may project a `VALIDATION_READY` formation into the existing canonical `LatentValueCandidate` model.

The projection stays:

```text
source_mode = LATENT_VALUE_DISCOVERY
```

It does not create:
- `NeedSignal`;
- payer truth;
- payment evidence;
- `ResourceSignal` control/availability;
- `BlockerSignal` transaction scope;
- `ROUTE_TESTABLE` status.

Those must still be proven through the existing Resource Imbalance and transaction layers.
