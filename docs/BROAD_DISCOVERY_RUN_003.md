# Broad Discovery Run 003

Run 003 deliberately moves away from the two structures that already received deep treatment (idle-asset repurposing and eldercare orchestration). Its purpose is to keep the China-primary discovery surface open and test whether the same governed web-research architecture can surface unrelated residual structures.

Dynamic research terms:

1. repair / refurbishment / second-hand / rental / trade-in / trusted quality / consumption substitution;
2. pet medical / boarding / home service / insurance / companionship / service friction;
3. flexible and project-based work / skill mismatch / idle professional capability / outsourcing;
4. warehousing / logistics / idle capacity / turnover / reverse logistics / returns / fulfillment;
5. platform merchants / traffic acquisition / fees / returns / multichannel operations / operating pressure.

The executed batch contains 30 provenance-bearing captures across all six governed research lanes. Every dynamic term has explicit contradiction search. Global-origin evidence requires China relevance and domestic corroboration.

Important interpretation boundaries:

- trade-in/subsidy activity does not prove organic recommerce demand;
- pet-market growth does not imply every service category is growing;
- flexible employment growth may reflect labor-market pressure rather than high-quality project-market matching;
- warehouse vacancy is not permanent underuse and can reverse as absorption recovers;
- merchant regulation and platform support are counterevidence to one-sided narratives of platform pressure;
- source-discovery records identify potentially useful observation surfaces, not validated world facts;
- `BROAD_DISCOVERY_READY` means research breadth only. It cannot promote taxonomy, Pattern, opportunity, payer, route or business truth.
