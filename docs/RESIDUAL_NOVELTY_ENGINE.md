# Residual / Novelty Engine

Status: `DISCOVERY INFRASTRUCTURE / FAIL-CLOSED`

Effective: 2026-09-15

## 1. Purpose

Exact source-native concepts often remain `UNBOUND` because the same wording does not recur often enough to satisfy the strict `ObservedPattern` gate. That is not failure and it is not permission to rename observations until they appear recurrent.

The residual layer preserves those unresolved identities and provides a governed bridge toward possible semantic clustering:

```text
exact UNBOUND source-native pattern
→ residual atom
→ optional cluster suggestion
→ evidence diversity / persistence assessment
→ explicit semantic review
→ reviewed alignment
→ existing emergent-taxonomy assessment
→ optional ontology-governance review
```

Every arrow is a separate state transition.

## 2. Source-native identities remain immutable

Residual atoms retain the exact:

- semantic primitive;
- source-native concept;
- geography;
- exact pattern id;
- claim refs;
- observation refs;
- source ids;
- actor ids;
- periods;
- epistemic states;
- missing exact-pattern evidence.

The residual layer does not rewrite a source claim into a broader concept.

`REPORTED` claims remain visible even when the exact `ObservedPattern` recurrence gate excludes them from `OBSERVED` recurrence counts. `INFERRED` claims remain visible but cannot satisfy novelty-cluster evidence gates.

## 3. Model clustering is suggestion only

A model may propose that several residual claims appear related. Such a proposal is always:

```text
MODEL_SUGGESTION
```

It may be checked for:

- observation diversity;
- source diversity;
- actor diversity;
- time persistence;
- source-concept diversity;
- primitive consistency.

Even when every evidence gate passes, its maximum state is:

```text
AWAITING_EXPLICIT_SEMANTIC_REVIEW
```

It cannot create a `ReviewedConceptAlignment`, ontology version, active taxonomy node, payer, demand, opportunity or business truth.

## 4. Semantic coherence is separately reviewed

Evidence co-occurrence is not semantic coherence.

A reviewed alignment must still provide explicit:

- definition;
- boundary;
- counterexamples;
- supporting exact claim refs;
- rationale.

Only then can the existing emergent-taxonomy gate assess whether the reviewed grouping is `RESIDUAL`, `CANDIDATE` or `PROMOTION_REVIEW_READY`.

`PROMOTION_REVIEW_READY` remains ontology-governance input only.

## 5. Unclustered residuals are first-class output

The engine must not optimize for 100% cluster coverage.

If an exact source-native pattern does not belong in any reviewed grouping, it remains visible as an unclustered residual. This protects contradiction, boundary and novelty signals from being erased by a desire for cleaner taxonomy.

For Broad Discovery Run 003, the existing five reviewed alignments cover 17 of 18 exact residual atoms. The remaining residual is:

```text
CONSTRAINT / TRADEIN_SUBSIDY_DEMAND_CONTAMINATION
```

It remains separate because the existing `CIRCULAR_RECOMMERCE_INFRASTRUCTURE` alignment is a `BEHAVIOR` grouping and subsidy contamination is a distinct constraint/counter-signal.

## 6. Truth boundaries

```text
EXACT_UNBOUND_PATTERN != FAILURE
MODEL_CLUSTER_SUGGESTION != REVIEWED_ALIGNMENT
EVIDENCE_GATED_CLUSTER != SEMANTIC_COHERENCE
REVIEWED_ALIGNMENT != TAXONOMY_PROMOTION
TAXONOMY_PROMOTION != ACTIVE_TAXONOMY
RESIDUAL_CLUSTER != OPPORTUNITY
REPORTED != OBSERVED
UNKNOWN != PASS
```

No residual workflow may contain automatic alignment creation, automatic ontology promotion, or commercial promotion.

## 7. Long-term role

This layer is how the system can discover new lower-level language without freezing today's categories into code:

```text
world changes
→ source-native observations
→ unresolved residuals
→ repeated unexplained structure
→ proposed grouping
→ explicit review
→ governed taxonomy evolution
```

The system is allowed to notice and propose. It is not allowed to silently redefine reality.
