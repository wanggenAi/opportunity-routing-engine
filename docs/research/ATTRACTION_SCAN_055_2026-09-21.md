# Attraction Scan 055 — 2026-09-21

## Boundary

Scan 055 left refunds, reimbursements, credits and disputes. It searched recurring paid non-recovery state transitions where a fixed machine action can directly change payer cost, margin or revenue, the buyer controls the action right, and exact incumbent preflight happens before deeper research.

## Result

**Commercial promotions: 0. Retained research formations: 0. FIRST_EXTERNAL_VALUE_FLOW: NOT_PROVEN.**

The scan tested six formation-diverse machine state transitions:

1. **Unused SaaS license reclamation** — direct avoided seat spend, but Zylo, Torii and Zluri already automate usage detection, reclaim/downgrade workflows and policy enforcement.
2. **Kubernetes workload rightsizing** — direct cloud-cost reduction, but CAST AI already continuously rightsizes workloads/nodes and reports realized savings.
3. **Hotel room-rate updates** — direct revenue action, but modern RMS products such as Duetto already automate real-time pricing and distribution.
4. **Restaurant item-availability sync** — protects order revenue, but Otter/Deliverect already own POS-to-delivery availability and menu synchronization.
5. **Twilio inactive-number release** — unusually clean open action with immediate recurring-cost reduction, but the unit economics are small, Twilio itself exposes the audit/release path, third-party number managers can automate it, and observed paid demand is low-ticket consulting.
6. **Per-shipment carrier/service selection** — direct cost-per-package action, but Shipium/EasyPost already make rate selection and label generation a core API control surface.

## Structural finding

```text
BUYER-OWNED ACTION RIGHT
+
FIXED MACHINE STATE CHANGE
+
DIRECT COST / REVENUE EFFECT
!=
UNOWNED CONTROL EDGE
```

If the decisive telemetry and action both live inside the same operating system or mature software category, the loop is easy for the native vendor or a category control plane to absorb. Open action rights solve authorization, but they do not create a distinct operator asset.

The one thinner surface in this scan—unused phone-number cleanup—shows the opposite failure: an action can remain technically open yet be too low-value and too self-service to support normalized orchestration economics.
