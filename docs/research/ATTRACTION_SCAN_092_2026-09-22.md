## F1 — Figma + token sync / design-to-code tooling

Current design-system teams still report Figma-to-code drift, manual token export and multi-library maintenance friction after adopting Figma.

Evidence includes:
- an agency on Figma Professional using Variables Pro because native variable library behavior was insufficient for its workflow;
- a Figma-based design-system team with a Tokens Studio Pro subscription that still struggles with variable/style setup and CSS extraction;
- a July 2026 founding designer who automated a workflow where a one-line color-token change could previously take about an hour of manual export, handoff and PR work.

The residual is real, but the strict two-account executed-double-payment chain is not equally well bound in public evidence.

The control-surface preflight is stronger:
- Tokens Studio already sells the paid token-sync/versioning/code-export layer;
- Figma Variables, Variables APIs, Code Connect and MCP increasingly absorb the same workflow;
- free/open-source plugins and custom CI/webhook automation provide substitutes;
- Figma plan permissions and repository write rights remain outside any new generic router.

Verdict: **demoted**.

## F2 — Webflow + membership/auth/billing layer

Webflow intentionally removed native User Accounts and the related APIs on January 29, 2026.

Current builders now assemble Webflow with Memberstack, Outseta, Stripe or custom code. One July 2026 startup describes an active Webflow + Memberstack + Stripe + Vimeo + custom-code stack and seeks a long-term specialist to finish and maintain it. A separate March 2026 user says recurring billing is no longer native and asks how to avoid roughly $30/month for a recommended provider.

Memberstack currently starts at $29/month monthly ($25/month billed yearly), so the second-layer market is real. But the strict executed-payment replication fails: one current stack does not publicly bind its exact bills and another participant is explicitly trying to avoid the second payment.

More importantly, Webflow itself documents an **ecosystem-first** strategy and recommends Memberstack and Outseta. The missing native feature is therefore not an ownerless edge; it is an intentional platform boundary with mature exact complements.

Verdict: **demoted**.

## F3 — Lightroom Classic + offsite photo backup

This formation contains the strongest directly stated double-spend account in Scan 092.

A February 2026 professional photographer explicitly reviews the subscriptions and platforms they pay for and lists:
- Lightroom Classic for editing;
- Backblaze for cloud storage.

Current Lightroom users also describe active Backblaze workflows over their computers and external drives. Adobe itself states that Lightroom Classic catalog backup **does not back up the referenced photos** and recommends independent backup; Backblaze currently charges $99/year for unlimited computer backup.

The critical distinction is causal: offsite backup is an adjacent resilience objective, not the same editing/catalog-completion outcome. Treating every second bill as “residual completion cost” would over-promote unrelated responsibilities.

The backup layer is also mature and directly owned by Backblaze, local disks, Time Machine, NAS and competing backup providers.

Verdict: **demoted**.
