## 2. System identity restored

The repository is an **Actor-First Regenerative Latent-Value Formation & Orchestration Engine**.

Its job is not to search for jobs, gigs, tenders, orders or arbitrage spreads.

Its job is to discover where real actors already carry durable potential energy, where another set of real actors or resources carries complementary potential energy, where reality is already producing partial/informal/expensive flow between them, and which recurring missing edge prevents that flow from becoming normal, repeatable and scalable.

Only after that relationship is evidenced may the engine design exchange mechanics and eventually project payer, need, resource and transaction truth.

## 3. The correct object is a regenerative value field

The preferred discovery object is not a transaction. It is a **regenerative value field**:

```text
LARGE / REPLENISHING ACTOR POPULATION A
+ DURABLE ENDOWMENT / STATE DISEQUILIBRIUM A
+ LARGE / REPLENISHING COMPLEMENTARY NODE POPULATION B

```

The field is still only a formation hypothesis until evidence binds each material claim.

## 4. Potential energy is not demand

A side can have strong potential energy without having an explicit need.

Examples of potential energy classes include newly available time, accumulated experience, idle productive capacity, fragmented skills, customer access without execution, execution without trust/context, capital without trusted deployment routes, data without callable use, space/equipment without viable scenario, relationships/reputation without exchange architecture, and repeated attention/behavior without transaction structure.

The system must not immediately turn these into a service, job, marketplace, customer lead or product idea. It must first reconstruct what state transition is blocked and why.

## 5. Two-sided potential is still not enough

```text
A HAS SOMETHING
+ B NEEDS SOMETHING
!= LATENT CONNECTION
```

The system requires evidence that reality is already trying to connect the nodes.

Connection pressure may appear as repeated informal help, repeated referrals, repeated borrowing/sharing, family/friend/manual coordination, expensive professional substitutes, repeated failed cross-boundary attempts, work being performed inside firms/families because no external route is trusted, repeated adaptation/workaround/substitution, adjacent institutions that partially approximate the relationship, or shared state changes that simultaneously strand value on one side and create pressure on the other.

The key question is:

> **What is reality already making these actors do around the missing connection?**

## 6. Regenerative circulation is required

A one-off task is not the target.

The candidate must have a plausible **Demand Pump / recurring event source** such as a demographic/lifecycle transition, recurring enterprise workflow, equipment/asset lifecycle, household state transition, repeated project cycle, technology-driven mismatch, installed-base events, or another structural process that naturally regenerates the same pressure.

Preferred loop:

```text
RECURRING STATE / EVENT FLOW
→ NEW STRANDED VALUE / NEW PRESSURE
→ LATENT CONNECTION FORMATION
→ ROUTED EXCHANGE
→ ACCEPTED OUTCOME
→ TRUST / RELIABILITY / ROUTING DATA
→ LOWER FUTURE FRICTION
→ MORE VALUE FLOWS
↺
```

A business is attractive when the **soil keeps producing new events**.

## 7. Scale is population + recurrence + standardizable edge

Before a formation deserves serious business attention, ask:

1. Are both sides large or replenishing populations/resources?
2. Does the underlying state transition recur?
3. Does connection pressure recur without founder effort?
4. Is the missing edge similar enough across events to standardize?
5. Can the operator own the edge without personally delivering every outcome?
6. Does each routed exchange create trust/data/coverage that improves later routing?
7. Can both sides bypass us without losing much value? If yes, the edge is weak.
8. Is the addressable field broad enough that one local sample is only a surface manifestation?

The goal is:

```text
Observation
→ Pattern
→ Opportunity Archetype
→ Regenerative Loop
→ Business System
```

not:

```text
Job Post
→ Quote
→ Spread
→ Call It A Business
```

## 8. Illustrative formation — not a target market

The constitutional `retirement transition × young digital capacity` example remains useful because it demonstrates the logic.

Potential energy A may include retirement-driven time, decades of expertise, relationships/reputation, some capital, and desire for autonomy/relevance/selective contribution.

Potential energy B may include digital/AI execution capability, adaptability, time, desire for income/experience/advancement, and weak trust/client access/industry context.

Possible third nodes may include SMEs with recurring bounded judgment/execution gaps, communities, trusted institutions, data/software, spaces/channels.

But the system must **not** jump to senior training, gig matching, expert marketplace, content service, consulting, or simply 'connect retirees and youth.'

It must first find repeated informal cross-generation work, referrals, partial paid/unpaid substitutes, repeated failed attempts, shared causal pressure and the recurring missing edge.

The example is a cognition calibration object, not a canonical market.
