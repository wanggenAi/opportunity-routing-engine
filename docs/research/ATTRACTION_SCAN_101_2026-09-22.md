## Why the boundary changed

Scans 099 and 100 found real non-generic control surfaces, but those controls repeatedly belonged to regulated principals, native platforms, access providers, identity authorities or bilateral data gatekeepers.

Scan 101 therefore asks a stronger upstream question before deep retention:

```text
CURRENT / RECENT CHINA PARTICIPANT-RECORDED FRICTION
+ INDEPENDENT OBJECTIVE CORROBORATION
+ CURRENT EXTERNAL ECONOMIC MOTION
+ DECISIVE CONTROL ASSET / RIGHT / ROUTING POSITION
  THAT AN INDEPENDENT SMALL OPERATOR CAN LEGALLY ACQUIRE
+ EXACT INCUMBENT / OPEN-SOURCE / GENERIC-AGENT / RIGHTS / MARGIN PREFLIGHT
→ RETAIN ONLY IF THE ACQUIRABLE CONTROL CREATES A REAL OPERATOR EDGE
```

## Result

| Formation | Acquirable control + money motion | Why it still fails |
|---|---|---|
| Self-hosted service public ingress | Cloud EIP/VPS/tunnel control + actual RMB 99/year cloud path | Commodity endpoint; direct cloud and free/bundled tunnels solve the same outcome cheaply |
| Burst GPU training capacity | Ownable GPU hardware/rentable capacity + current rental spend | Mature GPU clouds already price, reserve, migrate and route the commodity asset |
| Discounted multi-carrier outbound shipping | Enterprise carrier/API/rate access + actual per-order margin | Current margin is thin and mature aggregators already expose multi-carrier comparison/routing/fallback |

No formation survives all floors.

## F1 — Public ingress for self-hosted physical servers

A March 2026 Chinese participant wanted a cheap stable public IP only to expose a physical server inside the home network. The participant initially objected to introductory cloud pricing and later reported the problem solved through an older Alibaba Cloud account with an RMB 99 continuously renewable annual option; DDNS remained another route.

Participant source:
- https://www.v2ex.com/t/1202465

Alibaba Cloud currently defines EIP as a public IPv4 resource that can be independently purchased and held, then dynamically bound or unbound from supported cloud resources.

Objective source:
- https://help.aliyun.com/zh/eip/product-overview/what-is-eip

The control asset is therefore genuinely acquirable by an independent operator. But it is not scarce. Current tunnel products can remove the public-IP requirement entirely:

- https://developers.cloudflare.com/tunnel/
- https://tailscale.com/docs/features/tailscale-funnel

The participant's own outcome closed at RMB 99/year without a distinct operator, and generic agents can configure the same cloud/tunnel primitives.

**Verdict:** demoted.

## F2 — Burst GPU training capacity

A January 2026 Chinese participant lost access to four 8x4090 servers and explored cloud capacity, stating a need for roughly 16-32 4090-class GPUs simultaneously. Other current/recent China participant evidence shows training users switching to rented computers/GPU capacity and explicit rental budgets.

Participant sources:
- https://fast.v2ex.com/t/1189656
- https://staging.v2ex.com/t/1187214
- https://www.v2ex.com/t/1169390

GPU hardware is independently ownable, and GPU cloud capacity is commercially rentable. That makes this materially different from an upstream identity or regulatory right.

But AutoDL already provides the exact commercial control plane: exclusive GPU allocation, pay-as-you-go billing, reserved capacity, configuration changes, migration and multi-card handling. Its current public price surface also makes the commodity market transparent.

Objective sources:
- https://www.autodl.com/docs/price/
- https://www.autodl.com/docs/gpu/
- https://www.autodl.com/docs/qa/

Without evidence of privileged lower-cost capacity, a unique supply pool or founder-free embedded distribution, a new operator is another broker over an already-priced asset.

**Verdict:** demoted.

## F3 — Discounted multi-carrier outbound shipping

A February 2026 Chinese participant seeking a cheaper way to move heavy belongings received a firsthand report of using a third-party aggregated monthly-settlement courier platform for JD Logistics at a large discount.

Participant source:
- https://jp.v2ex.com/t/1191667

Another February 2026 developer launched a shipping mini-program. A commenter described a former colleague's similar multi-carrier API aggregator at roughly 1,000 users and RMB 3,000 monthly gross profit; the current developer said their own markup was only RMB 0.30 per order.

Operator source:
- https://www.v2ex.com/t/1192251

This formation passes the new entrance strongly: an independent operator can obtain enterprise API/rate access and money already moves through the route.

Yet the exact routing primitive is mature. Kuaidi100 currently exposes enterprise-authenticated carrier coverage, price query, order creation and labels. Its current `智选运力` product explicitly combines multiple capacity sources behind one integration with comparison and automatic fallback.

Objective sources:
- https://api.kuaidi100.com/document/5f0ff0a5bc8da837cbd8aef7
- https://api.kuaidi100.com/document/xorder
- https://api.kuaidi100.com/document/zhixuanyunli
- https://api.kuaidi100.com/document/dianzimiandanV2

The observed RMB 0.30/order markup exposes the main problem: the control is acquirable precisely because it is non-scarce, while support, disputes and customer acquisition remain real costs.

**Verdict:** demoted.

## Learning

Scan 101 validates the new acquirability filter: unlike Scans 099-100, all three decisive assets can plausibly be bought, owned or contracted through ordinary legal channels.

It also exposes a new failure mode:

```text
OPERATOR-ACQUIRABLE CONTROL
+ REAL PAYMENT
≠
DURABLE OPERATOR ADVANTAGE
```

Public ingress, GPU capacity and courier-rate routing are all valuable, machine-executable and monetized. They still fail when nearly any competent participant/operator can acquire the same control at similar terms and exact incumbents already package the routing layer.

One pass is not enough to promote "asymmetry" or "embedded distribution" into the next search ontology. Scan 102 should repeat the same acquirability + economic-motion floor on a second fresh, formation-diverse China sample.
