## Direction 1 — ZBJ ESN / alliance-store opportunity allocation

ZBJ publicly exposes a sophisticated native role and settlement structure.

Current official material shows:
- enterprise-service demand is platformized;
- the alliance-store model advertises system-fed opportunities;
- ESN decomposes a transaction into traffic, platform, sales and delivery roles;
- role-based settlement can be automated after transaction/acceptance events.

Representative sources:
- https://www.zbj.com/zt/jiameng/
- https://rule.zbj.com/ruleshow-11040.html
- https://task.zbj.com/index/

This proves:

`NATIVE_ROLE_SPLIT_AND_SETTLEMENT_EXISTS`.

But the paid roles are economically substantive:
- traffic-side compensation requires introducing a customer/opportunity;
- sales-side compensation requires follow-up/negotiation/signing;
- delivery-side compensation requires service execution.

A new operator does not receive value merely for neutral machine routing.

Verdict:
`NATIVE_SPLIT_CONFIRMED / ROUTER_ROLE_COLLAPSES_TO_ACQUISITION_OR_SALES_OR_DELIVERY`.

Representative sources:
- https://www.dayee.com/recommend.html

```text

= REFERRAL LABOR, NOT NARROW ROUTING CONTROL
```

Verdict:
`OUTCOME_ATTRIBUTION_CONFIRMED / FOUNDER_SEARCH_GATE_FAIL`.

## Direction 6 — Alipay AI Open Platform / Agent Pay

Alipay's 2026 AI ecosystem is materially more advanced than older generic payment rails.

The AI Open Platform describes:

The dedicated AI Pay platform, updated 2026-09-18, now separates:
- Vibe Pay;
- Skill Pay;
- Machine Pay;
- Token Pay;
- Agent Pay.

Agent Pay connects agents with product/service merchants and allows agents, under user authorization, to complete ordering, payment and result-return flows.

Sources:

This is the strongest new mechanism from Scan 009.

Alipay AI Pay now provides native monetization for machine-callable capability:
- Skill Pay lets Skill developers charge users across multiple Agent environments;
- Machine Pay supports metered charging for APIs/tools;
- SkillPay supports upload, sale, payment and direct developer settlement;
- current compatible environments listed by SkillPay include WorkBuddy, Doubao Work, Qianwen Office, Cursor, Codex and Claude Code.

Sources:
- https://aipay.alipay.com/
- https://aipay.alipay.com/docs/overview.html

Current SkillPay states:
- a submitted Skill can be listed after security review;
- the Agent shows product information and price;
- after user confirmation, Alipay AI Pay completes payment;
- funds go directly to the developer's Alipay account.

This proves:

```text
MACHINE_CALLABLE_CAPABILITY
→ NATIVE PRODUCT
→ NATIVE PAYMENT
→ NATIVE SETTLEMENT
```

It does **not** yet prove:

```text
USER HIGH-INTENT QUERY
→ PLATFORM AUTOMATICALLY DISCOVERS OUR ROUTING SKILL
→ SKILL IS INVOKED / PAID
```

The current public material still uses "upload / distribute / propagate" language and does not prove automatic intent-driven discovery for a new Skill.

Therefore this is a mechanism finding, not a retained formation.

## Structural conclusion

Across service marketplaces, referral systems, payment rails and agent ecosystems, the same rule repeated:

```text
NATIVE THIRD-PARTY PAYOUT
USUALLY PAYS FOR A DISTINCT CONTRIBUTION ROLE
```

Observed roles include:
- acquire the customer;
- introduce the opportunity;
- sell/close;
- supply the product;
- deliver the service;
- own a reusable digital capability.

The first four conflict with the current operator non-labor target when they must recur per transaction.

The fifth category — **owned reusable digital capability** — is different because one machine asset can execute repeatedly at near-zero founder labor.

That creates the next research frontier:

```text
SELF-REVEALING AGENT-NATIVE INTENT
+ MACHINE-DELEGATABLE ROUTING / DECISION FUNCTION
+ NATIVE SKILL/API DISCOVERY OR INVOCATION
+ NATIVE PER-CALL / PER-USE SETTLEMENT
+ NO COLD ACQUISITION
+ NO INVENTORY
+ NO HUMAN DELIVERY
→ WORTH HIGH-ATTRACTION TESTING
```

This is not permission to sell generic AI tools. The machine capability must itself perform a narrow economic routing function between real-world states/resources.
