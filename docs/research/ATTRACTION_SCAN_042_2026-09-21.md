# ATTRACTION_SCAN_042 — forced migrations are real pain but usually not an operator asset

Date: 2026-09-21  
Status: COMPLETE  
Commercial promotions: **0**

## Search rule

Scan 042 deliberately left claims/refunds/grants/tax relief and searched current operational state changes with:

- a hard or visible failure/deadline;
- existing software or operational budget;
- machine-executable digital delivery;
- no recurring expert delivery;
- no mature control surface.

## Results

Six forced platform/vendor changes were tested.

- **Google Content API → Merchant API:** intermittent 410 failures are already occurring for non-extended projects, but platform partners own their customers' migrations and the custom-code remainder is deterministic, customer-specific engineering.
- **Cloudflare Service Key → API Token:** the deadline is real, but the change is largely a documented credential/configuration migration without a distinct reusable operator asset.
- **Schiphol API platform → JWT/OAuth:** unmigrated integrations will stop on 1 October, but Schiphol provides exact guidance, access handling, support and office hours; the ecosystem is bounded and payer economics are unproven.
- **Booking.com OTA_HotelProductNotif v1.3:** Connectivity Partners already own the integration and Booking provides compatibility/migration guidance.
- **Azure Anomaly Detector retirement:** deployed demand is real, but exact drop-in replacement products such as Canary Edge are already live before retirement.
- **Salesforce Essentials retirement:** the platform owns consent, entitlement and the destination upgrade path.

## Main learning

```text
FORCED OUTAGE RISK
+
EXISTING SOFTWARE BUDGET
+
MACHINE-EXECUTABLE CHANGE
!=
INDEPENDENT OPERATOR BUSINESS
```

Vendor deprecations create urgent work, but the work is usually captured by the vendor, an existing platform partner, a drop-in replacement, or generic code agents.

## Scan 043

Reset again. Require evidence that somebody is already paying or repeatedly working around a live problem **before** forming a product theory, plus a distinct asset that compounds across customers.

Exclude:
- claims/refunds/grants/tax relief;
- vendor/API deprecation;
- generic one-off migration work.
