# Strategic Drift Incident — 2026-09-23

Status: **SYSTEMIC DRIFT IDENTIFIED / REMEDIATION IN PROGRESS**

## Incident

The repository's constitutional doctrine remained Actor-First Regenerative
Latent-Value Formation, but the executable scan loop drifted into an asset/cashflow
screen.

The drift did not happen in one jump. It compounded through a proxy chain:

```text
Scan 128
  small-operator-acquirable transferable micro assets
→ Scan 129
  require existing proceeds
→ Scan 130
  require operational control + contracted cashflow
→ Scan 131
  require complete economic tuple
→ Scan 132–140
  optimize buyer receipt window, entry economics, rent succession,
  prepaid-rent cursor and exact receipt rights
```

Each local refinement improved truthfulness inside the adopted lane. The lane itself
was no longer being re-proven against the constitutional objective.

## Root cause

### 1. Proxy-chain inheritance

The next search boundary was repeatedly derived from the strongest measurable
survivor of the previous scan. That converted a local validation variable into a
strategic objective.

```text
MEASURABLE SURVIVING PROXY
!=
NEXT COMMERCIAL ONTOLOGY
```

### 2. Drift audit checked the wrong failure class

The persisted `drift_audit` correctly checked things such as no old-address reuse,
no gate relaxation and no explicit property-only ontology lock. It did not require
proof that the scan still represented a regenerative value field.

Therefore a scan could truthfully report `gate_relaxation=false` while still moving
farther away from the repository's commercial purpose.

### 3. HIGH_ATTRACTION_BEACON lacked regenerative hard floors

The executable attraction gate tested bilateral motion, discoverability, match
resolvability, action callability, founder labor and generic-Agent substitutability.
It did not hard-require:

- replenishing Actor/Node A;
- replenishing Actor/Node B;
- recurring connection pressure;
- a recurring missing edge;
- a recurring event source / Demand Pump.

That omission allowed a clean single asset with attractive receipts to look
strategically strong even though it was only an investment object.

### 4. Evidence convenience became objective substitution

Source-bound cashflow, exact price, exact lease term and low recurring human labor are
useful downstream truth dimensions. They are unusually easy to quantify compared with
latent connection formation. Repeated optimization for those dimensions caused
Goodhart-style objective substitution.

## What did not fail

- The constitutional doctrine did not change.
- `UNKNOWN != PASS` remained correct.
- Fail-closed receipt and payment reasoning remained correct inside the wrong lane.
- TypeSafe/Jev remained shadow research advisory and did not create commercial truth.

The failure was **strategic admission before those downstream truth gates were ever
reached**.

## Remediation

The repair introduces two independent machine barriers.

### Attraction hard floor

`src/attraction_discovery.py` now requires regenerative-field evidence before a
formation can be `HIGH_ATTRACTION_BEACON`:

- A population replenishment;
- B population replenishment;
- recurring connection pressure;
- recurring missing edge;
- recurring event source.

An explicit task, asset listing, RFQ, gig, buyer brief, price spread or single
transaction is allowed only as downstream evidence unless independent regenerative
field evidence exists.

### Persisted-scan drift guard

`src/strategic_drift_guard.py` validates persisted scans. Beginning with
`ATTRACTION_SCAN_142`, CI requires:

- regenerative-field revalidation;
- explicit transaction seed not promoted into ontology;
- next search boundary re-derived from broad reality;
- evidence-bound regenerative gate on every high-attraction beacon.

Historical scans are preserved as incident evidence rather than rewritten.

## Disposition of Scan 141

PR #451 is not a business opportunity to choose between. It is a useful drift
artifact. It was merged concurrently while this remediation PR was open; that merge
is preserved as audit history only and must not become the basis or strategic prior
for Scan 142.

The Mianyang/Wuhu receipt work remains valid as narrow asset diligence evidence, but
it no longer controls commercial search direction. Live main history is not the
candidate pool, and a merged audit artifact is not a strategic prior.

The active machine state also closes every still-retained formation from the drifted
Scan 135/136/139/140/141 asset/cashflow chain with a strategic-quarantine closure.
This preserves source facts while preventing Jev or a future agent from reopening the
lane merely because a historical formation remained in `retained_research_formations`.
