## Verdict

`DEMOTED_FROM_CURRENT_COMMERCIAL_FORMATION / WEAK_DOWNSTREAM`

The prior work correctly established that a tool-using Agent can expose bounded,
machine-verifiable acceptance conditions. That technical truth is retained.

The commercial interpretation was too generous.

## Why the attraction is weak

The proposed layer primarily enters after:
- the buyer has already decided to buy;
- the supplier has already been selected;
- scope and contract economics are substantially fixed;
- development has already consumed most project value;
- the remaining event is closeout / acceptance / retest.

That position can contain real friction without containing enough economic energy to
support a new independent commercial rail.

For this formation, the default value is closer to:
- reduced ambiguity;
- cleaner retest;
- lower closeout/rework friction;

than to:
- unlocking a previously blocked transaction;
- changing vendor selection;
- controlling budget allocation;
- creating new revenue;
- materially changing resource allocation before commitment.

Therefore the formation is downstream of the main value-creation and value-allocation
decision.

## Market-context boundary

The demotion does not require a blanket claim that Chinese buyers never care about
acceptance. That would be too broad.

The stronger and more transferable finding is structural:

- when budget, vendor and scope are already substantially committed;
- when most value creation/allocation has already occurred;
- when the remaining bridge mainly improves closeout process quality;

the formation has weak default attraction unless the bridge still controls payment
release, prevents material loss/risk, satisfies a hard compliance/safety boundary, or
determines whether the transaction can complete.

Country/industry-specific acceptance behavior may strengthen or weaken this conclusion
only when supported by current evidence.

## New doctrine extracted from the failure

Before spending scarce external validation capital, every retained formation must
answer:

1. Where in the value chain can the intervention occur?
2. At that moment, are budget/scope/vendor/resource decisions still movable?
3. Does the bridge control or materially change revenue, budget, cost, risk, resource
   allocation or transaction completion?
4. What materially happens if the bridge does not exist?
5. Is participant pull observable in behavior, or is the analyst merely noticing a
   process imperfection?

A real friction that occurs after value allocation is locked is not attractive by
default.

```text
REAL FRICTION != ATTRACTIVE POSITION
LATE-STAGE PROCESS IMPROVEMENT != COMMERCIAL LEVERAGE
VALUE ALREADY ALLOCATED + DECISIONS LOCKED -> DEFAULT DEMOTION
```

Exception:
A late-stage layer may survive when it still directly controls payment release,
material loss/risk, compliance/safety, or whether the transaction can complete.
