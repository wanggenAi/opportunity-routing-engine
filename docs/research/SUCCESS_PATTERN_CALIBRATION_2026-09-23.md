# Success-Pattern Calibration — 2026-09-23

Status: **DISCOVERY METHOD / DOES NOT OVERRIDE ATTRACTION FIELD**

## Why this exists

Scans 120–125 became increasingly efficient at finding already-mature low-FTE,
profitable, positive-OCF entities. That is useful if the mission is acquisition or
control of an existing cash-flow asset. It is too narrow as the only discovery lens
for a founder who wants to form a new high-attraction business soon.

The fix is **not** to lower commercial truth gates and **not** to run low-attraction
MVP experiments. The fix is to enlarge the upstream search universe with empirical
knowledge from businesses that demonstrably achieved strong usage, revenue,
distribution or transaction flow.

```text
REAL SUCCESS / FAILURE CASES
-> DISTILL REUSABLE MECHANISMS
-> SEARCH PRIORS / DIRECTION GENERATORS
-> FRESH CURRENT REALITY
-> ORIGINAL ATTRACTION FIELD HARD FLOORS
-> ONLY HIGH-ATTRACTION SURVIVORS
-> DECISIVE REVERSIBLE REALITY TEST
```

Hard boundary:

```text
SUCCESS PRECEDENT != CANDIDATE EVIDENCE
FAST != ATTRACTIVE
CHEAP EXPERIMENT != WORTH DOING
DEADLINE != PERMISSION TO LOWER GATES
```

## What the first calibration set says

The first set deliberately mixes different business shapes and one negative control.

- **Levels portfolio**: tiny operator footprint can work when intent is digitally
  visible, delivery is machine-native and distribution compounds; however his
  accumulated public audience is an unusual advantage and cannot be assumed.
- **Carrd**: capability-narrowing can reduce explanation/support while preserving a
  very broad user population. "Narrow" can mean one sharply bounded capability rather
  than one tiny industry.
- **Photopea**: immediate utility can exploit existing task intent without founder
  persuasion. Zero-friction entry matters when the value jump is obvious.
- **OpenRouter**: independent callable rails + existing high-frequency intent +
  neutral orchestration + usage settlement is a powerful routing shape.
- **Skyscanner partner rail**: monetization can ride the same successful transaction
  rather than requiring a separate sales motion.
- **Acquire.com**: both sides self-identify with strong transaction intent; structured
  evidence and workflow compress diligence/trust.
- **BuiltWith**: repeated automated observation creates a decision asset whose value
  compounds across time and customers.
- **Reddit $89k solo SaaS self-report**: useful negative control. Real revenue driven
  mainly by cold outreach and lifetime deals can still be strategically unattractive
  here because founder acquisition is the engine and recurrence is weak.

## Mechanisms worth transferring

These are not products or verticals. They are attention priors:

1. **Self-revealing intent before the decision closes.**
   The system should see an actor already trying to do something; it should not create
   the desire through founder persuasion.
2. **A narrow, immediately legible state jump.**
   The connection should be understandable without a long sales explanation.
3. **Self-service / machine-native activation.**
   The bridge should start with a call, click, upload, event or standard transaction,
   not a bespoke consultation.
4. **Distribution embedded in existing behavior.**
   Search, sharing, transaction surfaces, public state changes, APIs, registries or
   repeated communities are stronger than recurring cold outreach.
5. **Monetization attached to the same value flow.**
   Subscription, usage, take-rate, affiliate/revenue share or settlement economics
   should align with the useful outcome.
6. **Low recurring human delivery.**
   The operator can improve the control plane without becoming the permanent worker.
7. **Compounding outcome/data asset where reality permits it.**
   Each observation/transaction should ideally improve routing, trust, coverage or
   the next decision.

## What changes in Scan 126

Do **not** continue turning the mature-company screen into an ever-narrower gate chain.
The Scan 125 low-FTE/profit/OCF/fresh-control boundary remains a valid **cash-flow
asset search lens**, but it is no longer the only discovery lens.

Scan 126 should be a formation-diverse, precedent-calibrated broad scan:

- use at least the precedent mechanisms above as independent search priors;
- search fresh China-relevant current reality across unrelated domains;
- do not reuse precedent verticals as candidates;
- do not inherit Scan 015 or Scan 125 verticals;
- do not admit anything before the existing Attraction Field hard floors pass;
- success examples can increase where we look, never what we are allowed to believe.

## Launch-decision clock

Operational deadline: **2026-09-30**.

The deadline is deliberately asymmetric:

- if a genuine high-attraction formation exists, spend scarce external validation
  capital on its single decisive unknown;
- if none exists, expand sources, precedent cases and mechanism diversity;
- **never** create an experiment merely to satisfy the deadline;
- **never** weaken bilateral pull, discoverability, match resolvability, callable
  action, founder-independence, operator control, non-genericity or economic truth.

A low-attraction project remains forbidden even on the deadline.
