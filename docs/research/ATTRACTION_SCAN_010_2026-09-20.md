## Stronger residual topology — private context × public live rail

The more defensible unresolved surface is:

```text
USER / ENTERPRISE PRIVATE CURRENT STATE
+
EXTERNAL LIVE PUBLIC / PARTNER RESOURCE WORLD
+
A DECISION WINDOW THAT IS OPEN NOW
+
A CROSS-DOMAIN JOIN THAT THE EXTERNAL PLATFORM CANNOT PRECOMPUTE
+
MACHINE-RESOLVABLE ROUTING
+
NATIVE SKILL DISCOVERY + PER-USE PAYMENT
→ WORTH DEEPER SEARCH
```

Examples of **private state** include:
- an active project file;
- a BOM;
- current equipment state;
- a private qualification packet;
- a contract / order / inventory state;
- a private software repository;
- a workflow's accumulated context.

The point is not privacy itself.

The economic reason is that an incumbent controlling the external public rail does **not automatically own the user's private current state**, so the decisive join may remain outside the incumbent's product boundary.

## Important constraint

Private context alone is not a moat.

Scan 010 directly killed private-repository × vulnerability/license data because SCA tools already own that join.

Therefore the next scan must still require:
- the incumbent has not already integrated the private/public join;
- the private state is naturally present in an Agent/workflow;
- the join changes a real action;
- the decision is machine-resolvable;
- the action rail remains callable;
- the capability can be paid without founder acquisition/delivery.
