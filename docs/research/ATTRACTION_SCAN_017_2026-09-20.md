## Direction 1 — Electronic trade-document interoperability / finance routing

### Why it initially looked attractive

China's `促进和规范电子单证应用规定` took effect on 2026-09-01.

It recognizes a broad set of electronic transport, warehousing and cargo-insurance
documents and explicitly covers reliable-system operations such as:
- issuance;
- storage;
- modification;
- conversion;
- transfer;
- pledge;
- circulation.

Primary source:
- https://www.cac.gov.cn/2026-04/17/c_1778166821092785.htm

This creates real movement from paper/legal friction toward transferable digital rights.

The apparent missing edge was:

```text
SHIPMENT / DOCUMENT / FINANCING CONTEXT
+
CARRIER
+
EBL PLATFORM
+
COUNTERPARTY
+
BANK
+
JURISDICTION
→ WHICH DIGITAL DOCUMENT RAIL CAN COMPLETE
  ISSUANCE → TRANSFER → FINANCE → SURRENDER?
```

### Contradiction

The exact interoperability bottleneck is now being standardized by the industry.

DCSA currently provides:
- Platform Interoperability (PINT) API;
- common interoperability legal framework;
- Control Tracking Registry;
- standardized receiver validation and transfer behavior.

Five eBL providers — CargoX, edoxOnline, TradeGo, WaveBL and eTEU — adopted the
DCSA interoperability framework in 2026, allowing cross-platform eBL exchange.

Sources:
- https://dcsa.org/our-mission/ebl-interoperability-platform
- https://dcsa.org/newsroom/five-ebl-platforms-adopt-dcsa-interoperability-annex
- https://dcsa.org/standards/bill-of-lading

A live Thailand-China transaction already demonstrated an eBL flowing between
IQAX / ICE CargoDocs and participating banks.

Source:
- https://www.iqax.com.cn/zh-hans/newsroom/banks-embrace-ebl-interoperability-with-live-cross-platform-trade-finance-transaction-in-thailand-and-china-zh-hans/

The financing layer is also moving upstream into platform/bank infrastructure:
- WaveBL directly supports digital trade-finance presentation;
- China Construction Bank's 2026-09-20 `数币达·励付` links cross-border settlement,
  electronic-bill platforms and financing.

Sources:
- https://wavebl.com/trade-finance/
- https://www.ccb.com/chn/2026-09/20/article_2026092009174289979.shtml

### Verdict

```text
INTEROPERABILITY GAP WAS REAL
BUT
INTEROPERABILITY IS BECOMING THE PLATFORM STANDARD ITSELF
+
BANK / DOCUMENT PLATFORMS ARE ABSORBING FINANCE CONNECTIVITY
→ NO CLEAR INDEPENDENT CONTROL LAYER
```

Verdict:
`DEMOTED / STANDARDS_AND_PLATFORM_LAYER_INTERNALIZING_THE_EDGE`.

Do not build another electronic-document directory or generic compatibility advisor.

## Direction 2 — Commercial-space shared test / intermediate-verification capacity

### Why it looked attractive

Commercial-space companies face expensive, scarce and specialized environmental,
reliability and verification infrastructure.

In 2026 the National Space Administration began organizing the first batch of
commercial-space public test and intermediate-verification platforms, explicitly
encouraging resource sharing and joint construction.

Sources:
- https://www.cnsa.gov.cn/n6758823/n6758839/c10741560/content.html
- https://www.beijing.gov.cn/zhengce/zhengcefagui/202605/t20260506_4638063.html

The attraction is real:

```text
EXPENSIVE SPECIALIZED TEST CAPACITY
+
COMMERCIAL-SPACE FIRMS WITH TIME-SENSITIVE TEST DEMAND
→ SHARED CAPACITY CAN REDUCE DUPLICATE CAPEX AND WAITING
```

### Kill boundary

The missing step is not merely locating a laboratory.

A real route can depend on:
- exact test standard;
- specimen geometry/mass;
- fixture/interface requirements;
- thermal/vibration/EMC envelope;
- security/qualification constraints;
- sequencing;
- engineering interpretation.

The public-platform initiative validates the resource-sharing need, but current evidence
does not establish a standardized, multi-provider, machine-callable booking rail where
the router can select a provider without recurring test-engineer judgment.

### Verdict

`DEMOTED / HIGH_VALUE_RESOURCE_SHARING_BUT_EXPERT_MATCHING_AND_CALLABILITY_NOT_PROVEN`.

Keep as a world-model signal, not a retained commercial formation.

## Direction 3 — Retired PV-module recycling route

### Why it looked attractive

A 2026 six-ministry guidance document targets cumulative comprehensive utilization of
250,000 tons of retired PV modules by 2027 and explicitly supports building used-PV
module trading platforms.

It also requires owners to verify the qualification and technical capability of
entrusted transport/utilization/disposal parties.

Primary source:
- https://www.miit.gov.cn/zwgk/zcwj/wjfb/yj/art/2026/art_95cd611e3c664dfc96cd76ace1aa24d7.html

This proves:
- growing forced supply;
- real compliance constraints;
- multiple downstream utilization paths;
- active policy support for trading infrastructure.

### Kill boundary

Current market execution still frequently depends on:
- site inspection;
- physical-condition judgment;
- manual quotation;
- logistics negotiation;
- provider-specific acceptance.

The same guidance says retirement-evaluation standards and inspection methods still
need further development.

Therefore:

```text
REAL FRAGMENTED MARKET
+
LARGE COMING VOLUME
!=
CURRENT MACHINE-CALLABLE ROUTING RAIL
```

### Verdict

`DEMOTED / REAL_FRICTION_BUT_PHYSICAL_EXPERT_AND_MANUAL_QUOTE_DEPENDENCE`.

Revisit only if standardized inspection + multi-provider transaction rails become live.

## Direction 4 — Product carbon-footprint certification routing

### Why it looked attractive

China's 2026 product carbon-footprint label certification pilot now has:
- unified general implementation rules;
- 17 product-specific rules;
- 26 selected certification institutions.

Primary source:
- https://www.samr.gov.cn/xw/zj/art/2026/art_722720ac85c844f78cbaa02445a27ee8.html

The apparent route was:

```text
PRODUCT / EXPORT MARKET / CUSTOMER REQUIREMENT
→ CHOOSE CERTIFIER + CERTIFICATION PATH
→ MINIMIZE SUPPLEMENTARY WORK / TIME / COST
```

### Contradiction

The obvious connection layer is already becoming a feature of carbon-management and
certification SaaS platforms: institution aggregation, certification connection,
progress tracking and consulting are already offered commercially.

Even without relying on one vendor claim, the underlying certification process includes
site inspection and professional carbon-footprint verification. The Market Regulation
Administration's first certificates were issued after formal verification and peer
review.

Source:
- https://www.samr.gov.cn/xw/sj/art/2026/art_1d953f8b7a7742d5a70d788df354271e.html

### Verdict

`DEMOTED / PLATFORMIZED_CONNECTION_PLUS_PROFESSIONAL_VERIFICATION`.

A generic "AI carbon certification router" would collapse into certification brokerage
or consulting unless it owns a materially distinct outcome graph.

China's green-certificate market is large and fast-growing. In Q1 2026, national

### Verdict

`DEMOTED / EXCHANGE_AND_AGENT_LAYER_ALREADY_OWNS_PROCUREMENT_CONTROL`.

## Cross-direction learning

Scan 017 reveals a recurring trap:

```text
POLICY OR STANDARD OPENS A NEW MARKET
+
DIGITAL IDENTITY / REGISTRY / API / PLATFORM APPEARS
→ LOOKS LIKE ROUTING OPPORTUNITY

BUT IF THE SAME REFORM ALSO CREATES
  THE REGISTRY
  + THE MATCHING PLATFORM
  + THE INTEROPERABILITY STANDARD
  + THE TRANSACTION / SETTLEMENT RAIL
THEN
  THE OBVIOUS ROUTER IS ALREADY INSIDE THE INFRASTRUCTURE
```

The next search should therefore move one layer outward.

## New Scan-018 boundary

Prefer situations where **each individual platform is mature**, but the economically
decisive event is generated by a state transition that crosses independent domains.

Preferred form:

```text
MATURE PLATFORM A OWNS ITS STATE
+
MATURE PLATFORM B OWNS ITS STATE
+
NEITHER OWNS THE CROSS-DOMAIN JOIN
+
THE JOIN IS TIME-SENSITIVE
+
THE JOIN CHANGES A REAL ACTION
+
OUTCOME FLOWS BACK
+
NO RECURRING EXPERT / FOUNDER EXECUTION
→ POSSIBLE UNOWNED ROUTING EDGE
```

Examples of structure, not vertical priors:
- external event changes whether an already-listed resource should be moved now;
- a right or capacity exists on one platform while a time-sensitive state appears on
  another;
- independent transaction rails each see only their own success history;
- the economically decisive cross-domain state is not a public static lookup.

Do not simply search for another newly launched government platform.
