## Why this layer exists

In Xuzhou, high-trust technical and industrial relationships should not be modeled as if any public actor can be approached and mobilized directly. A realistic route often passes through organizations whose published mission already includes technology transfer, industrial coordination, enterprise service, validation, training or joint problem-solving.

The important question is not only `who has resources?`, but also:
- which organization is allowed to coordinate them;
- what that organization is already trying to achieve;
- what benefit participating actors can receive;
- what evidence is required before treating the organization as an actual sponsor.

## New network observation

The most important correction is structural:

```text
TECHNOLOGY MANAGER
can be affiliated with Institution A
+
use resource network of Institution B
+
route a problem toward Institution C / expert team
```

Therefore `backing` should not be modeled as one all-powerful sponsor. It can be a **stack of institutional roles**:

```text
LEGITIMACY / AFFILIATION
+ TRANSACTION INFRASTRUCTURE
+ EXPERT / RESULT DISCOVERY
+ INDUSTRY ACCESS
+ VALIDATION / PILOT INFRASTRUCTURE
```

Different institutions may supply different layers.

This is closer to the project's core doctrine: discover under-combined institutional resources and design a lawful route across them.
