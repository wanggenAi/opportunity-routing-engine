## Examined paid flows

### Vibe-coded app pre-launch security

Current buyers pay for review of AI-built Supabase/Next.js/Stripe applications, including $50-$100/hour security review work. The pain is real.

It closes because:
- live jobs already attract dense specialist supply;
- purpose-built vibe-code scanners now exist;
- mainstream security platforms provide SAST, secrets detection, pentesting and AI autofix;
- the residual architecture review still requires expert engineering.

### Voice AI acceptance testing / regression

Current voice-agent deployments explicitly budget for acceptance tests, difficult scenarios and post-change regression.

It closes because the exact control surface is already a mature category:
- Coval;
- Hamming;
- Cekura;
- simulation, regression, production evals, human QA, compliance and vendor bakeoffs are already products rather than white space.

### TikTok Shop suspension / removal appeals

Current $100-class appeal work can show fewer than five proposals. Buyer urgency and sparse visible supply are real.

It closes because:
- TikTok owns adjudication and reinstatement rights;
- each case depends on platform evidence, account history and human escalation;
- there is no independent callable action rail for an operator to own.

### EUDR TRACES-NT integration

A current paid Zoho integration proves friction around the EUDR SOAP API. The EU operator API is callable.

It closes because:
- each customer's ERP/CRM schema, credentials and product/plot data differ;
- compliance meaning cannot be inferred from a successful SOAP call alone;
- the reusable adapter is ordinary integration code while the valuable remainder is customer-specific.

### EU product pre-launch compliance review

A current PPE review pays $300 and has fewer than five proposals.

It closes despite apparent supply scarcity because standards interpretation, claims substantiation, certificate review and labeling legality remain expert judgment with real liability. This violates the no-recurring-expert-delivery floor.

### LLM / RAG / agent evaluation setup

Current buyers pay for evaluation architecture, adversarial test corpora and regression gates.

It closes because the control plane is already populated by LangSmith, Langfuse, Braintrust, Arize/Phoenix and adjacent observability/eval platforms. Custom work is implementation consulting around an established product category.
