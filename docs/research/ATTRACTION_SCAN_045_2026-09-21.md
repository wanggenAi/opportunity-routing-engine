## Search rule

Scan 045 required all of these together:

- direct payer or repeated workaround evidence;
- day-one value for a single customer;
- machine-executable digital delivery;
- each execution creates a permissioned, non-sensitive cross-customer reusable asset as a byproduct;
- the asset improves later quality, cost, speed or access;
- no network-scale cold start;
- no mature incumbent owns the same asset;
- no recurring expert delivery.

## Results

Six structures were tested: web-access/proxy routing, self-healing browser automation, HS-code classification, email verification, business-phone reputation, and unified API connector maintenance.

They prove that the desired business physics are real. Unfortunately, the cleanest reusable assets are already infrastructure categories:

- Bright Data already owns massive proxy/access network scale.
- Browserbase/Stagehand already persists reusable browser-action caches and self-healing automation.
- Avalara already owns billable tariff-classification content and APIs.
- Hiya already owns the phone-reputation network and its authorization rail.
- Merge already owns hundreds of maintained connector mappings and observability.

Email verification shows the opposite failure mode: the workflow has day-one value and repeated signal generation, but the decisive raw observations contain identifying customer data and cannot simply be assumed legally reusable across customers.

## Main learning

```text
DAY-ONE VALUE
+
EXECUTION-CREATED REUSABLE ASSET
!=
EARLY WHITE SPACE
```

The abstract search has reached diminishing returns. When an asset is clean, reusable and valuable, it tends to become infrastructure quickly. When it is not already infrastructure, reuse rights often become the limiting factor.

## Scan 046 reset

Stop starting from an abstract asset shape.

Search current reality for **already-paid micro-flows where specialized supply is still sparse or the category is visibly early**, then apply the existing hard floors to those real flows. This is a change in discovery source/order, not a required product mechanism.
