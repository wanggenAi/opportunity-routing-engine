# ATTRACTION_SCAN_040 — recent monetary rule changes are not enough

## Search rule

Scan 040 moved earlier than the mature recovery categories killed in Scan 039.

It searched for recently created or materially expanded monetary entitlements, refunds, credits, grants or policy windows where:

- money is newly recoverable or claimable;
- public rules plus customer-authorized data make execution plausible;
- delivery is digital or delegatable;
- an exact end-to-end incumbent has not already occupied the action loop.

## Results

Six current formations were tested across the UK, US, Australia and Korea.

- **UK BICS manufacturing electricity relief:** materially valuable and third-party submission is explicitly allowed, but BICS-specific energy/compliance advisors are already preparing applications before the first window opens.
- **US Section 45F employer child-care credit:** the 2026 credit expansion is large, but dedicated calculators, documentation guides and CPA filing services already exist.
- **UK SFI26 farm payments:** up to £100,000 per agreement year, but SFI-specific planning software and rural-agent workflows already serve the application loop.
- **Australia PRF Safeguard Transformation Stream Round 2:** very large grants, but award is competitive and requires project/engineering judgment; specialist grant consultancies already sell the application service.
- **Korea new-merchant card-fee refund:** real retroactive money, but card companies refund automatically to settlement accounts, leaving no claim/action edge.
- **Busan small-business energy voucher:** newly opened and rule-based, but only KRW 200,000 per business with direct app submission and official support, so normalized orchestration economics are weak.

## Main learning

```text
RECENT MONEY / RULE CHANGE
!=
TEMPORARY WHITE SPACE
```

The rule-change clock alone is too late in many public schemes: specialized advisors can form before the application window opens.

The next useful boundary is stricter:

```text
RECENT MONETARY CHANGE
+
NON-AUTOMATIC BENEFIT
+
DETERMINISTIC / MACHINE-RESOLVABLE ELIGIBILITY
+
HIGH PER-BENEFICIARY VALUE
+
BENEFICIARY UNIVERSE CAN BE ENUMERATED OR MACHINE-IDENTIFIED
+
NO EXACT APPLICATION / RECOVERY / ADVISORY INCUMBENT
+
NO RECURRING EXPERT DELIVERY
```

## Scan 041

Search broadly for changes satisfying that full conjunction. Do not turn government grants into the required product shape; private contract, tariff, platform or commercial-rule changes remain in scope.
