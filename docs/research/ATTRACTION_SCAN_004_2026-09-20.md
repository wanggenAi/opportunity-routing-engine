## High-attraction signal retained

### Working title

**Legacy Equipment Harvest Parts Graph / 工业旧设备器官库**

### The non-obvious connection

2026 policy and market flows are pushing more industrial equipment into:
- replacement;
- auction;
- idle-asset sale;
- retirement;
- recycling;
- remanufacturing.

At the same time, other factories continue to operate legacy equipment whose:
- OEM spare parts are discontinued;
- imported parts have long lead times;
- drawings are missing;
- exact replacement is hard to source;
- a small failed component can stop a much more valuable production asset.

The hypothesized connection is:

```text
RETIRING / IDLE WHOLE MACHINE
(low whole-machine or scrap-state value)
        ↓
identify parent model / serial / BOM / recoverable organs
        ↓
verified HARVEST PART
        ↓
MATCH to still-operating compatible legacy machine
        ↓
restore production / avoid waiting for OEM / avoid premature machine replacement
```

The value object is not "sell used machines".

It is the **tool/machine → component → compatibility → condition → harvest route**
graph that makes a donor machine searchable as an emergency spare-parts reservoir.

## State-dependent value jump

The same physical component can occupy radically different value states.

For the retiring-machine owner:
- it may be a low-liquidity component inside an idle asset;
- the whole asset may be auctioned in bulk or treated as recycling material.

For the operator whose compatible production machine is stopped:
- that exact component may restore a line;
- its economic value is linked to avoided downtime rather than scrap value.

This is the central attraction signal:

```text
LOW-VISIBILITY RETIRED-ASSET ORGAN
+
HIGH-URGENCY COMPATIBLE FAILURE
→ SHARP STATE-DEPENDENT REPRICING
```

## Why generic Industrial Downtime Recovery Router was not retained

A broader concept was tested:

`one outage → route among exact stock / substitute / repair / borrowed spare /
reverse engineering / on-demand manufacturing`.

It has strong buyer urgency and value jump.

But it risks requiring:
- fault diagnosis;
- engineering judgment;
- compatibility judgment;
- safety classification;
- provider selection across unrelated service types;
- case-specific recovery planning.

That creates a material risk that the "router" is actually an expert maintenance
service disguised as software.

Therefore the broad recovery router is currently:

`LOWER_ATTRACTION / TOO_WIDE / OPERATOR-LABOR RISK`.

The harvested-parts graph survives because its bridge is narrower and more
standardizable.

## Attraction Brief — F1

### A-SIDE TEMPTATION

"If this machine is being retired anyway, a searchable verified component can be worth
more than anonymous bulk scrap and may improve asset recovery."

### A-SIDE EVIDENCE

Equipment-renewal flows, public disposal, industrial auctions, idle-equipment markets
and internal reuse / dismantling behavior are current and observable.

### B-SIDE TEMPTATION

"My legacy machine is stopped or at risk because the OEM part is discontinued or slow.
If you can identify a compatible tested donor component quickly, its value is tied to
production recovery, not its material cost."

### B-SIDE EVIDENCE

Current parts centers, emergency spares, reverse-engineering services and local
replacement businesses exist precisely because operators already spend effort on this
problem.

### OPERATOR TEMPTATION

Potentially high if the operator owns:
- the identity / compatibility graph;
- source visibility;
- harvest routing;
- verification status;
- response-time / reliability data;

while dismantling, testing, logistics and installation remain delegated capabilities.

### OPERATOR NON-LABOR TEST

Fail if every request requires the founder to personally:
- diagnose the machine;
- identify the part from first principles;
- negotiate dismantling;
- judge safety;
- test components;
- install the part;
- warranty the machine.

Survive only if the system can progressively standardize:
- machine identity;
- part identity;
- compatibility;
- condition evidence;
- harvest feasibility;
- verified provider roles.

### CONNECTION WOW

```text
A MACHINE ABOUT TO BECOME SCRAP

→ another factory's production asset comes back online
```
