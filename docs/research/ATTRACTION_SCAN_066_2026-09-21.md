## Search question

Scan 065 showed that deterministic, repeatable and machine-verifiable external spend is a clean delivery-shape signal but often points directly into mature SaaS/app categories.

Scan 066 raised the floor again: require at least two independent current buyer-side signals for the same bounded deterministic unit, while rejecting anything already established as a named mature app, SaaS or managed-service category.

## Result

Six formations were tested. None survived.

The decisive distinction is now economic evidence quality:

```text
TWO BUYERS REPORT THE SAME PAIN
!=
TWO BUYERS ALREADY PAY AN EXTERNAL PARTY
FOR THE SAME BOUNDED RECURRING EXECUTION UNIT
```

Where the exact deterministic unit really is invariant across buyers, mature software categories frequently already exist. Where the category has not formed, one of three things usually breaks: confirmed recurring money motion, cross-buyer unit invariance, or callable data/action rights.

## Formations

### F1 — Ecommerce marketplace payout → ledger reconciliation

Independent current buyers on QBO, Xero and NetSuite still report weekly/monthly manual reconciliation of marketplace payouts, fees, refunds and timing differences.

This is real and objectively settleable, but Link My Books and Synder already sell the exact recurring multi-channel accounting/reconciliation layer.

**Closure:** multi-buyer demand passes; pre-category gate fails.

### F2 — AI coding-tool spend attribution by team/project/client

A current 40-developer engineering organization built an internal nightly collector because finance required AI spend by team. Agencies and AI-heavy teams report the same attribution problem.

However public evidence does not show two independent buyers already paying a recurring external operator for this exact unit. Cross-tool execution is also blocked by uneven telemetry: Claude Code exposes usable session detail while some seat-based coding tools do not expose equivalent project-level data. API-side attribution is already rapidly productizing.

**Closure:** strong current demand; confirmed second money motion and complete data rights fail.

### F3 — Agency recurring client-report assembly

Multiple current agency operators report recurring hours spent assembling monthly reports. The deterministic subunit is clear: refresh data, populate template, brand, render and deliver.

AgencyAnalytics, Swydo, Rollstack and other products already sell those exact functions. Residual value is increasingly interpretation and client-specific narrative.

**Closure:** two-buyer signal passes; mature category gate fails.

### F4 — TikTok Shop creator commission / settlement reconciliation

Current sellers report difficulty reconciling platform fees, creator commissions, Shop Ads attribution and payouts.

But two independent external recurring payments for the same reconciliation unit are not proven. TikTok is also expanding native monthly commission receipts, exports and affiliate APIs.

**Closure:** problem signal passes; external money motion and independent control fail.

### F5 — PDF invoice/receipt → accounting-system entry

Independent current accounting users still manually re-key invoice and receipt data from PDFs.

Nanonets and Rossum now provide document ingestion, extraction, validation, duplicate handling, exception review and ERP/accounting integrations as paid productized workflows.

**Closure:** multi-buyer deterministic demand passes; mature IDP/AP category gate fails.

### F6 — Small-business spreadsheet normalization/deduplication

Current paid listings and workers prove people still pay for spreadsheet cleanup.

But current buyer evidence is often one-time, while each file carries buyer-specific schemas and ambiguity rules. The same recurring bounded transformation is not established across two independent buyers.

**Closure:** paid work exists; recurring invariant-unit gate fails.

## Learning

Scan 066 removes another false-positive class: **two independent buyer problem reports**.

The next floor should use only confirmed money motion. Scan 067 must start from two independent buyers who already paid or repeatedly pay an external party for the same bounded deterministic unit. Internal scripts, employee labor, manual pain, stated willingness to pay and seller asking prices do not count as equivalent evidence.
