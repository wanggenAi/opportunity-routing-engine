## Purpose

Scan 026 moved out of dominant consumer transaction platforms and tested active enterprise spending and
operational-loss flows.

It deliberately asked a harder question than "is there waste?":

```text
IS MONEY ALREADY LEAKING?
IS THE STATE MACHINE-READABLE?
IS THE ACTION LOOP ACTUALLY UNOWNED?
CAN VALUE BE CAPTURED WITHOUT RECURRING EXPERT / FIELD DELIVERY?
```

The answer across the tested set was **no retained formation**.

## Cloud commitments / idle resources

The waste is real, but cloud cost optimization is already a mature native control surface.

Tencent's current FinOps solution includes cost analysis, budgets, anomaly detection, optimization advice and
savings plans. Alibaba likewise exposes savings plans, resource packages and cost-management tools.

Sources:
- https://cloud.tencent.com/document/product/555/126906
- https://www.alibabacloud.com/help/zh/ecs/cost-optimization-faqs
- https://www.alibabacloud.com/help/zh/user-center/white-paper-on-alibaba-cloud-cost-managements-solution

Verdict: **demoted — native FinOps control surface**.

## Software-license shelfware

Unused enterprise software licenses are direct money leakage, but Chinese SAM/ITAM products already monitor
license use and automatically recover idle floating licenses.

SMARTLIC publicly describes:
- software inventory;
- utilization monitoring;
- idle-license release;
- ITSM integration;
- renewal/procurement support.

Source:
- https://www.smartlic.cn/

Verdict: **demoted — exact entitlement-utilization incumbent**.

## Supplier quality claims / 8D / NCR

Supplier-caused defects create real quality cost, but modern QMS products already include supplier claims,
SCAR/NCR, 8D, CAPA, quality-cost analysis and ERP/MES/WMS integration.

Sources:
- https://www.keshengcloud.com/products/capabilities/qms
- https://www.kyber-platform.com/products/manufacturing-operations/qa
- https://www.omnexsystems.cn/supplier-quality-management-software

The remaining root-cause/responsibility work frequently requires quality-engineering judgment.

Verdict: **demoted — QMS control surface + expert judgment**.

## Cargo-damage insurance claims

Cargo loss/damage is a direct recoverable-money flow, but current insurance-tech providers already expose
cargo-insurance APIs, automated claim pre-review and telemetry-based loss assessment.

Source:
- https://www.winray.tech/products/api-platform

Insurers/brokers still own settlement authority.

Verdict: **demoted**.

## Compressed-air leakage

The loss can be large. Festo states that many industrial compressed-air systems lose 10–20% through leakage;
SUTO describes leak detection, management software and reporting. Aden and Ingersoll Rand provide detection,
ROI analysis and repair/optimization services.

Sources:
- https://www.festo.com.cn/cn/zh/e/support/additional-services/compressed-air-energy-efficiency-audit-id_2012747
- https://www.suto-itec.com.cn/zh-hans/leak-detection/
- https://www.adenservices.com/zh-hans/technical-assets-management/compressed-air-leak-management/
- https://ingersollrand.com.cn/zh/parts-and-service/performance-services/

The residual execution is physical inspection/repair.

Verdict: **demoted — existing sensor/service stack + recurring field work**.

## Maximum-demand electricity cost control

Industrial maximum-demand peaks can directly increase the electricity bill, but EMS systems already forecast
load, apply priority rules and automatically delay/shed controllable loads.

Examples:
- https://www.hisine.com/index.php/Index/product/sid/18/id/66.html
- https://www.sxiai.cn/products/energy-management/

Verdict: **demoted — mature EMS control loop**.

## Freight invoice overcharge recovery

This was the closest "direct money back" candidate.

The hypothesized edge was:

```text
CARRIER BILL
× CONTRACT RATE
× SHIPMENT EVENT
→ FIND OVERCHARGE / DUPLICATE / WRONG SURCHARGE / SLA REFUND
→ CLAIM MONEY BACK
```

But exact incumbents already exist.

Shipmore publicly describes automated carrier-bill ingestion, contract-rate comparison, duplicate/incorrect
surcharge detection, service-guarantee refund detection, automatic dispute submission and refund tracking.

OOCL Logistics likewise provides multi-carrier freight audit with AI validation against contract rates and
operational data.

Sources:
- https://shipmore.com/products/audit
- https://www.oocllogistics.com/schi/solutions/supplychainmanagement/freightaudit/Pages/default.aspx

Verdict: **demoted — exact freight-audit recovery incumbent**.

## Why zero retention is correct

Every tested category had at least one decisive failure:
- mature native control surface;
- exact incumbent;
- settlement/action authority owned elsewhere;
- recurring expert/field delivery;
- or no distinct operator asset.

The durable learning is:

```text
COST LEAK != WHITE SPACE
AUTOMATED DETECTION != UNOWNED ACTION
B2B != UNPLATFORMIZED
```

## Scan 027 boundary

The next scan should stop searching generic "cost optimization" and instead search **value that is already
contractually owed to a business but is missed because a trigger was not detected, reconciled or claimed**.

Examples of mechanism classes—not assumed winners—include:
- volume rebates;
- tiered discounts;
- service-level credits;
- price-protection credits;
- contractual penalties/credits;
- vendor incentives;
- refund/credit entitlements.

The required shape is:

```text
SIGNED / ACCEPTED COMMERCIAL TERM
+ MACHINE-DETECTABLE TRIGGER
+ MONEY / CREDIT ALREADY OWED
+ CLAIM / CREDIT ACTION
+ NO MATURE RECOVERY CONTROL SURFACE
```

Scan 027 must falsify each class rather than assume contract leakage is a business.
